# Attention modes

The five attention modes are independent interface choices. All are off by default. Enable any combination in Visitor settings. They do not assess a person or make medical claims.

## Focus

Enable Focus, then explicitly choose a registered destination in the workspace bar above the current content. Other navigation is de-emphasised and content away from that destination uses quieter colour. Nothing is hidden or disabled. Restore full view turns Focus off in one action. Return to focus destination uses the existing navigation and lock checks. A removed destination is shown as unavailable and cannot be opened from this control.

## Low stimulation

Low stimulation uses a quieter neutral palette without changing the saved seed colour. It reduces non-essential shell motion and composes with the device reduced-motion preference. Non-essential narration stops. Informational, success and progress notices without actions are muted in the active stack. Warnings, errors and actionable notices remain visible. The notification centre retains all session records, including muted ones, and its opener shows both active and recorded counts. This does not delete records or change exports.

## Time awareness

The workspace bar shows elapsed minutes since this page session opened and since an observed meaningful change. Input, change and navigation activity update the latter clock. Pointer and keyboard activity postpone idle prompts without pretending a change happened. Wall time includes background time and is explicitly described as elapsed time, not work measured. Clocks are transient, start again after reload and do not enter history or exports.

## One thing at a time

Enable this mode to see one explicitly chosen next action above the current content. Edit, save and clear are deliberate controls. The single line is bounded to 500 characters and persists only in this browser. It is never inferred from documents, forms, tabs or activity. It is excluded from ordinary settings exports and revision history. A separately labelled export saves only that next action to a local text file when requested. Do not enter secrets. Clearing removes its browser-storage entry. Reset settings turns the mode off; its independent text remains until explicitly cleared.

## Momentum

An opt-in gentle prompt appears after at least five minutes without observed interaction, only while the page is visible and no registered draft provider reports an active operation. It appears once per idle episode. Pointer or keyboard interaction within its controls, and Tab navigation toward them, keep the prompt mounted until the chosen snooze or dismiss action completes. Dismiss keeps it closed until another interaction begins a new episode. Not now snoozes it for exactly fifteen minutes. Interaction postpones the next prompt, and returning from the background starts a fresh idle period. English and Cantonese humour levels independently style the reassurance without changing the timing facts. School mode keeps its English-only presentation.

## Storage and verification boundaries

Mode switches and the safe focus destination identifier use ordinary versioned settings, revisions and explicit settings export/import. Older settings without a focus identifier restore with no chosen destination. Invalid identifiers are rejected. Next-action text uses separate bounded local storage and is not included in diagnostics, captured fixtures, ordinary export or history. Storage refusal keeps the current saved action and reports the limitation.

Controlled-clock tests cover background truth, observed changes, idle episodes, exact snooze, active operations, dismissal and interaction. Storage tests cover empty, invalid, oversized and unavailable inputs. Notification tests preserve all records and keep warnings, errors and actionable messages visible. A deliberately shortened snooze turned its regression red before the correct duration was restored. Source checks do not establish built accessibility, layout, colour intensity, motion inside every component or installed timing. Those runtime checks remain pending with the integration owner.
