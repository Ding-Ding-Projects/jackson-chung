# 未儲存草稿決定

保留畫面可以從 `src/state/drafts.ts` 使用 `registerDraftProvider(owner, {id, label: {en, yue}, isDirty, save?, discard, canDispose?})` 登記草稿提供者。回傳函數會喺組件拆卸時解除登記。擁有範圍會跨過開放 shadow host，尋找最近嘅保留分頁；獨立畫面使用明確 standalone 範圍。所有草稿內容同回調狀態都保留喺提供者自己嘅即時畫面。

頁面框架主機關閉回調喺關閉分頁前，會檢查同一批提供者。程式內原生關閉掣會檢查全部已登記提供者。忙碌嘅 `canDispose` 否決會保留畫面。錨定決定介面提供儲存、查看放棄確認同緊急取消。Escape 同瀏覽器歷史導覽會取消並交還焦點。儲存必須真正清除每個提供者嘅未儲存狀態，先可以關閉。儲存失敗或未提供時，畫面會繼續開啟。

放棄介面會列明受影響提供者，要求兩把獨立鎖匙同完整滑桿，然後先提供最後放棄操作。搜尋只會篩選顯示嘅提供者，唔會暗中改變涵蓋全部提供者嘅決定範圍。每次破壞性回調前，會先喺記憶體附加安全操作資料。草稿內容永遠唔會喺此序列化、封存、記錄或匯出。處理私人暫存輸入嘅提供者可以刻意唔提供儲存路徑；畫面會說明限制，並要求明確放棄。除非原有流程另外提供復原機制，否則無法復原已放棄私人內容。

## 界線

只有已登記提供者受保護，唔會聲稱未登記表單或任意外部分頁狀態修改受保護。重新載入瀏覽器後還原有類型嘅公開／非秘密草稿尚未實作。瀏覽器／作業系統關閉視窗、程序終止同原生選單快捷鍵，需要真正原生橋接查詢此 API；呢段界線原先只涵蓋 renderer 程式內關閉控制。批量關閉亦只有喺呼叫者逐一查詢受影響分頁嘅主機／API 時先受保護。

## 焦點避位

頁面框架透過 ResizeObserver 同可視範圍變更量度實際 sticky／fixed 標題高度。文件使用真實避位值設定捲動內距、焦點邊距同跳過連結。焦點進入被遮住控件時，會捲動到量度所得標題下面。實際原生／瀏覽器幾何同鍵盤操作仍然係獨立執行接納項目。

## 原生關閉握手

原生主程序喺釋放任何 renderer 內容前截取 BrowserWindow 關閉事件。佢建立一個隨機要求 ID，並要求隔離 preload 已登記關閉回調處理共用草稿提供者。只接受來自確切可信套件主框架、包含目前要求 ID 同嚴格布林決定嘅回應。批准只授權一次重複關閉事件，之後會移除範圍內監聽器。同時出現嘅關閉嘗試會共用待處理決定，唔會開多個競爭提示。

preload 只提供 `onCloseRequested(callback)`，唔提供原始 IPC 或獨立可呼叫批准函數。取消、回調拒絕、renderer 中斷、導覽、格式錯誤或過期回應，同兩分鐘逾時都會保持視窗開啟。程式內原生關閉操作亦會到達同一 BrowserWindow 關閉事件。原生 broker 只喺成功 `will-quit` 時拆卸，所以取消關閉唔會令仍在運作嘅工作區斷線。

原始碼測試涵蓋關閉事件狀態機、發送者／要求驗證、取消、重複嘗試、逾時／導覽／renderer 中斷後失效、嚴格 preload 批准同監聽器拆卸。實際安裝後作業系統關閉、Alt+F4、未儲存提供者介面、取消同重新操作，仍然要喺重建套件桌面驗證。呢個握手唔會防止強制終止程序或已被入侵嘅可信 renderer。

### 標題稍後改變尺寸

量度到標題高度變更後，會安排一次動畫影格檢查最深層焦點控件，包括開放 shadow root 內嘅控件。只有控件同標題遮擋範圍相交時先捲動。相同高度重複量度唔會再安排捲動。畫面外控件、固定浮層、對話框、原生標題控制同刻意提供嘅跳過連結都會排除。焦點同文字選取永遠唔會被重新指定。

集中控制器測試會執行真正框架量度同 ResizeObserver 方法。移除稍後尺寸變更排程，就會喺測試重現焦點被遮擋；還原排程後，同一控件會一次移到量度所得標題下面。原始碼測試唔能夠代替真實可視範圍／縮放／鍵盤擷取判定。
