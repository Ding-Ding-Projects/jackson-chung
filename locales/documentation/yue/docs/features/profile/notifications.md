# 通知

所有功能上下文通知都會進入共用瀏覽器程序儲存區。資訊同成功訊息會喺七秒後退場，進度更新會喺十秒後退場。警告同錯誤會保留，直至用家明確關閉。滑鼠停留或鍵盤焦點會暫停倒數，離開後重新提供完整閱讀時間。訊息會喺右下角有範圍限制嘅可捲動區域排列，永遠唔會開啟資訊模態對話框。

通知中心同作用中排列共用一個畫面高度預算，另有可到達嘅開關。中心開啟時，標題同關閉掣會留喺有範圍嘅共用內容捲動區之外；該區包含搜尋、展開 regex 建立器及全部歷史記錄。大型建立器會同歷史一齊捲動，唔會令歷史高度跌到零；作用中通知亦喺分配範圍內獨立捲動。主容器唔會隱藏超出範圍嘅控制。來源結構檢查會保護呢個安排；實際畫面幾何仍需要建置後驗證。

通知中心可以重看今次程序工作階段嘅作用中同已關閉訊息。歷史只保留喺記憶體，唔會寫入瀏覽器儲存、遙測、記錄、匯出或分頁中繼資料。重新載入就會清除。訊息只應提供安全用家摘要，唔可以包含憑證、檔案內容或私人資料。

關閉、中心控制同操作都使用有名稱嘅 Material 控件，目標至少 44px。資訊使用禮貌螢幕閱讀器狀態宣告；警告同錯誤使用警示。中心同操作標籤支援英文、廣東話同雙語。訊息主體保留來源功能提供嘅用字，唔會嘗試逆向翻譯歷史字串。已登記時，中心使用共用本機搜尋同相鄰 regex 建立器；啟動階段會先用一般文字搜尋。

`publishNotification(message, kind, {title, actions})` 接受重試、復原、開啟或詳情嘅可選有限範圍回調。回調只留喺記憶體，永遠唔會序列化。操作進行中會顯示忙碌，阻止重複執行，並安全處理失敗而唔洩露例外內容。如果操作未能完成，通用持續錯誤會引導用家返回原有流程。

## 顯示偏好

通知分類框架、忙碌提示同操作失敗指引各有五款英文及五款廣東話。兩種語言分別按自己嘅趣味值選字。第一級嚴肅用字同第五級活潑用字保留相同分類及復原事實。來源訊息、明確標題、操作標籤、檔名、數目及其他來源事實永遠唔會改寫。明確標題原字保留，下面另加通知分類框架。作用中同歷史項目共用同一顯示函式。

顯示會讀取目前有效設定，包括有效本機排程對語言、趣味、表情符號及低刺激嘅覆蓋，唔會改動儲存嘅基本設定。上學模式強制嚴肅英文框架、忙碌文字及操作失敗指引，唔會覆寫已儲存趣味級別或來源通知文字。排程引擎可保留及匯入呢啲值；此使用點唔會新增排程編輯控制，亦唔會聲稱其他地方已使用全部排程欄位。

表情符號開關控制標題旁相關裝飾。裝飾係獨立且無障礙樹隱藏嘅元素，唔會加入控制、無障礙名稱、訊息記錄、通知搜尋、匯出或剪貼簿內容。關閉會完全移除裝飾。低刺激只喺作用中排列隱藏非必要而冇操作嘅項目；警告、錯誤、可操作訊息及完整歷史仍可到達。

## 驗證及界線

聚焦來源執行亦涵蓋五種分類、三種語言模式、全部五級獨立趣味值、原樣來源事實、作用中／歷史一致、隱藏裝飾及關閉狀態、實際排程邊界及基本設定還原、上學顯示同必要記錄保留。刻意改壞設定使用、語言、趣味、裝飾及歷史選擇都會令檢查失敗。建置後顯示同無障礙仍待驗證。集中測試涵蓋逾時分類、持續警告及錯誤、可重看已關閉歷史、暫停及恢復、訂閱解除、重複操作抑制、回調拒絕、無效輸入同防護歷史副本。實際建置焦點、排列版面、螢幕閱讀器宣告、語言切換、種子顏色對比同完整逐畫面批量／歷史功能，仍然要進一步驗證。批量刪除／匯出通知同持久歷史尚未實作。
