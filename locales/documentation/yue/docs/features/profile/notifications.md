# 通知

所有功能上下文通知都會進入共用瀏覽器程序儲存區。資訊同成功訊息會喺七秒後退場，進度更新會喺十秒後退場。警告同錯誤會保留，直至用家明確關閉。滑鼠停留或鍵盤焦點會暫停倒數，離開後重新提供完整閱讀時間。訊息會喺右下角有範圍限制嘅可捲動區域排列，永遠唔會開啟資訊模態對話框。

通知中心可以重看今次程序工作階段嘅作用中同已關閉訊息。歷史只保留喺記憶體，唔會寫入瀏覽器儲存、遙測、記錄、匯出或分頁中繼資料。重新載入就會清除。訊息只應提供安全用家摘要，唔可以包含憑證、檔案內容或私人資料。

關閉、中心控制同操作都使用有名稱嘅 Material 控件，目標至少 44px。資訊使用禮貌螢幕閱讀器狀態宣告；警告同錯誤使用警示。中心同操作標籤支援英文、廣東話同雙語。訊息主體保留來源功能提供嘅用字，唔會嘗試逆向翻譯歷史字串。已登記時，中心使用共用本機搜尋同相鄰 regex 建立器；啟動階段會先用一般文字搜尋。

`publishNotification(message, kind, {title, actions})` 接受重試、復原、開啟或詳情嘅可選有限範圍回調。回調只留喺記憶體，永遠唔會序列化。操作進行中會顯示忙碌，阻止重複執行，並安全處理失敗而唔洩露例外內容。如果操作未能完成，通用持續錯誤會引導用家返回原有流程。

## 驗證及界線

集中測試涵蓋逾時分類、持續警告及錯誤、可重看已關閉歷史、暫停及恢復、訂閱解除、重複操作抑制、回調拒絕、無效輸入同防護歷史副本。實際建置焦點、排列版面、螢幕閱讀器宣告、語言切換、種子顏色對比同完整逐畫面批量／歷史功能，仍然要進一步驗證。批量刪除／匯出通知同持久歷史尚未實作。
