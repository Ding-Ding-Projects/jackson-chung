# 個人頁及文件導覽

## 網頁外觀決定

擁有人明確要求個人作品集唔採用 Material Design 風格。因此網頁採用獨立嘅編排字體、色彩、間距同導覽。呢項外觀例外只適用於 `website/material-design`，唔會豁免桌面或擴充功能嘅外觀、無障礙、語言支援、響應式版面、實際控制項或其他交付要求。獨立保留嘅合約基準只容許呢一對畫面同合約。未知嘅全域豁免同擴大範圍嘅畫面例外都會被拒絕。欠缺證據仍然代表未完成。

個人頁主要部分使用片段目的地。文件路徑格式係 `#docs/<encoded article identifier>/<encoded heading identifier>`。文章識別碼可以包含斜線，斜線會連同識別碼一齊編碼。瀏覽器上一頁同下一頁會還原所選文章同標題。

文件閱讀器載入本機隨附嘅 `documentation.json` 清單。有分類索引時，分類按鈕會開啟索引，否則會開啟該分類第一篇隨附文章。文章按鈕、相關閱讀、相對 Markdown 連結同同篇文章標題連結，全部使用同一導覽路徑。標題識別碼固定可重現，重複標題會加數字後綴。選擇文章會將焦點移到閱讀區；選擇標題會聚焦並捲動到該標題。文章或標題未有提供時，畫面會明確顯示狀態。

Markdown 透過安全文字範本呈現。原始 HTML 保持為文字，執行程式或檔案 URL 協定會被拒絕。閱讀器唔會執行嵌入腳本、載入外部 Markdown，亦唔會用原始碼連結代替隨附文章內容。未支援嘅 Markdown 仍然可以當文字閱讀。

## 驗證

集中測試涵蓋編碼文章路徑、格式錯誤輸入、相對文章解讀、跨來源拒絕、標題目標、重複標題識別碼、原始 HTML 處理同不安全連結協定。實際瀏覽器導覽同輔助技術行為要另外進行執行驗證。

## 保留工作區整合

頁面框架按分頁 ID 連接可重用分頁主機，每個分頁有獨立 DOM 節點。切換分頁時，非作用中節點會留喺記憶體，並設為隱藏同 inert。關閉分頁會釋放其節點。新增分頁目的地選擇器可以為同一目的地建立多個獨立分頁。只會儲存一般目的地標題同工作區中繼資料；頁面框架永遠唔會序列化本機表單值同文件內容。畫面可以用 `data-unsaved="true"` 明確標示未完成工作，阻止一般關閉。目前唔會聲稱已自動偵測全部工具嘅未儲存工作。

文件分頁喺記憶體保留自己嘅文章同標題路徑。只有作用中文件分頁會更新瀏覽器片段。全域歷史導覽只更新作用中分頁，唔會改動所有保留閱讀器。重新載入會還原中繼資料，唔會還原私人表單內容或每個分頁嘅閱讀狀態。

共用指令浮層接收所有已登記目的地，負責 Ctrl+Shift+F，頁面框架亦有可見開啟掣。舊有框架快捷鍵唔會同佢競爭。操作、焦點、私隱同溢出版面接納，仍然要喺實際建置瀏覽器或桌面畫面驗證。

公開網頁採用個人作品集頁首，主要導覽包括關於我、工作經驗、作品同聯絡。更多選單提供其他個人內容、文件同本機工具。個人內容保留分頁狀態，但不顯示工作區分頁列；工具內容仍然提供分頁控制。由更多選單開啟搜尋後，關閉時會將焦點返回仍然可見嘅選單標題。桌面配套保留獨立工作介面。
