# 專業個人頁及作品

- [個人頁及文件導覽](navigation.md)

個人頁展示 Jackson Chung 提供嘅學歷、資訊科技支援經驗、義工服務同可轉移嘅零售能力。上架補貨同商品陳列係求職方向，唔係聲稱做過嘅工作。公開聯絡資料只有電郵同多倫多。

作品部分連接 Ding Ding Projects 旗下六個現有公開項目。介紹按各項目公開 README 撰寫，保留開發狀態限制。列出項目唔代表個人獨立創作，亦唔代表已驗證全部執行行為。

公開履歷係獨立產生、唔含電話號碼嘅 PDF。原先提供嘅附件唔會加入呢個儲存庫或部署。

## 設定及私隱

訪客語言同顯示偏好只影響本機呈現。公開個人資料並非訪客可以編輯嘅記錄。電郵連結會開啟訪客選用嘅郵件程式，冇託管聯絡表格收集提交資料。

## 驗證

已檢查原始碼類型同單頁 PDF 呈現。公開路徑、流動裝置操作同完整無障礙證據，仍然要按實際建置輸出記錄先可以確認。

## 隨附文件圖片

Markdown 圖片只會呈現直接放喺 `public/captures/` 嘅隨附點陣圖片。喺呢個分類可以使用 `../../../public/captures/example.png` 呢類文章相對路徑。閱讀器按文章位置解讀路徑，再映射到部署嘅本機 `captures/` URL。支援 PNG、JPEG、WebP 同 GIF。必須提供非空白純文字替代說明，由 Lit 安全轉義。圖片會配合文章可用闊度，同時保留原有比例。

外部圖片、協定相對位址、data URL、憑證、絕對或私人路徑、編碼路徑、已命名路徑段之後嘅向上跳轉、巢狀擷取資料夾同 SVG 都唔支援，亦唔會變成圖片要求。原始 HTML 永遠唔會執行。被拒絕嘅圖片標記會改為純文字替代說明。路徑有效唔代表檔案存在，亦唔代表圖片像素已獲接納為證據；實際隨附檔案交付同呈現版面要另外驗證。現有文章連結、標題錨點同獨立閱讀路徑維持原有行為。
