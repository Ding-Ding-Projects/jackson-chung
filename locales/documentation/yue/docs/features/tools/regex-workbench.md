# 錨定的正規表示式工作台

`src/components/regex-workbench.ts` 會登記 `jc-regex-workbench`。其獨立工作程序位於 `src/workers/regex-workbench-worker.ts`。這個共用元件已可供搜尋功能擁有者整合；它不會自動替換現有本機搜尋或指令面板實作。

## 整合 API

把每個來源輸入放進該實例的 `search` 插槽。提供唯一而穩定的 `fieldId`、現有 `FeatureContext`，以及訪客的 `funnyEn`/`funnyYue` 數值。沒有全域作用中欄位或共用查詢單例。旁邊的按鈕會開啟附於該欄位的內嵌面板，窄版面亦然。`openFor(input)` 支援另一個明確的相鄰觸發控制。關閉或按 Escape 會把焦點還原至來源輸入。

擁有者輸入會在輸入時呼叫 `setSearchState({query})`。`getSearchState()` 會傳回 `{query, pattern, flags, mode}` 的副本。預設為純文字。字面輸入會同步成已跳脫的模式；切換至正規表示式時會保留該跳脫意圖。原始模式修改會把查詢同步回同一來源。旗標保持獨立，並由引擎驗證。

監聽可跨 shadow 邊界並向上冒泡的 `jc-regex-change`，其資料為 `{fieldId,state,valid,error}`。從 `state.query` 同步擁有者輸入的值；不要把 `valid: false` 理解成可以保留過時搜尋結果。有效評估會發出目前狀態，而已取消、被取代、無效及逾時的評估會維持無效。`jc-regex-apply` 只帶有 `{fieldId,state}`，絕不包含樣本、擷取或取代輸出。套用會更新欄位所屬的暫存歷史，並還原焦點。主體篩選必須在自己的有界本機工作程序使用所選模式及旗標；單憑語法驗證，不能證明任意記錄比對安全。

整合清單仍由主體負責：每個現有搜尋、設定篩選、下拉選單及內容選單篩選，都需要自己的實例及繫結。本單元沒有新增獨立搜尋輸入；插槽放置的是主體欄位的實際輸入。元件存在不代表現有偏好設定、指令面板及工具搜尋已遷移。

## 真實引擎及建構

評估使用目前瀏覽器的 ECMAScript `RegExp`。支援的旗標及進階結構會透過實際編譯探測確認。JavaScript 不會提供確切的引擎實作版本，因此不會根據瀏覽器名稱推斷。引導片段涵蓋字面值、跳脫／碼點、字元類別、Unicode 屬性、集合交集／相減、錨點、擷取、非擷取群組、選擇、量詞、前後查看及反向參照。依賴 Unicode 的片段會選取所需的 `u` 或 `v` 模式。原子群組、佔有式重複、條件、子程序及內嵌修飾符仍會顯示；不支援的探測結果會停用相關控制，並提供對應引擎說明。不會模擬 PCRE 或 .NET。

逐個語法單元的註解會提供偏移、詞法種類及群組深度，作為結構化說明。這明確只是詞法註解，不是引擎剖析樹，亦不宣稱涵蓋每種結構的語義。語法是否有效仍以編譯為準。瀏覽器不提供引擎追蹤或回溯步驟，因此兩者均不可用。

## 測試及取代

工作程序會傳回實際比對值、UTF-16 範圍、編號／具名擷取，以及選用的 `d` 擷取範圍。導覽以 `g` 列舉，同時保留黏附／Unicode 語義；取代則使用原本所選旗標。空比對在 `u`/`v` 模式按碼點前進，其他情況按 UTF-16 碼元前進，包括安全地越過結尾。

取代支援 ECMAScript `$$`、`$&`、前綴／後綴、編號及具名範本。展開會在建立大型輸出前受限，測試亦會直接與原生取代行為比較。預期結果案例會報告實際布林比對結果，以及是否符合預期。案例、樣本及擷取結果只會暫存。計時只量度一次評估，不是複雜度證明。啟發式檢查會標示巢狀重複、重複選擇、反向參照及大型樣本，但沒有警告絕不代表能安全處理對抗性輸入。

## 上限、私隱及持久儲存

模式及查詢最多為 2,048 個 UTF-16 碼元；樣本 20,000；取代文字 4,096。最多接受 20 個案例，每個 2,000 個字元，總計 20,000 個字元。結果最多 200 個比對，每個最多 50 個擷取。比對／擷取文字總量及取代輸出，各自不超過 40,000 個字元。評估有 150 ms 協作式預算，以及包括啟動時間的 300 ms 父層工作程序期限。父層會在逾時、取消、修改、關閉或中斷連接時終止工作程序。舊結果不能驗證較新的狀態。

不會進行遠端評估、記錄或自動持久儲存樣本。已套用的查詢歷史留在元件實例內。儲存本機模式片段需要明確同意及穩定欄位 ID；缺少穩定 ID 時，片段只會暫存。片段 JSON 帶有版本，最多 20 筆記錄，匯入上限為 64 KiB；其結構會拒絕樣本／擷取或未知欄位。匯入內容在明確儲存前只會暫存。匯出／複製只由使用者操作觸發，包含模式及旗標，並提醒使用者分享前檢查模式內容。移除已儲存片段會保留其他已儲存記錄，亦不會順帶把新匯入的暫存片段持久儲存。

## 驗證及尚待驗收項目

`node --test tests/tools-regex-workbench.test.mjs` 會轉譯實際工作程序原始碼，並在主機 ECMAScript 引擎執行。測試涵蓋純文字／正規表示式模式、無效語法、沒有比對、Unicode、多行、零寬度處理、擷取、與原生取代結果一致、案例結果、執行時功能探測、獨立欄位狀態同步、匯入／私隱上限、擷取輸出上限，以及災難性回溯時真正終止獨立工作程序。嚴格 TypeScript 檢查涵蓋兩個檔案。

實際瀏覽器控制互動、螢幕閱讀器／焦點行為、窄版面／高縮放，以及主體搜尋介面的完整整合仍待完成。Node 引擎測試不能證明這些狀態。這裡不提供完整語義 AST、即時執行追蹤，或對抗性安全保證。
