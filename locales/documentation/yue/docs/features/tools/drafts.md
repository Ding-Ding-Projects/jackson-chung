# 本機工具的暫存草稿

轉換器、佇列輸入、手動驗證器表格及新登記表格，都會向共用分頁擁有者登記明確的草稿提供者。提供者只檢查指定欄位及已選檔案的參照。這項整合不會加入表格序列化、密鑰歷史、密鑰匯出或密鑰持久儲存。

佇列輸入會保留瀏覽器的選取資料，每次持久寫入成功後才推進游標。部分儲存失敗時，其餘來源仍可重試；先前已加入佇列的來源會保留。放棄只會移除未儲存的選取資料及其欄位參照，不會改動原檔案或持久工作。輸入、佇列處理及保管庫操作進行期間，會阻止棄置。

直接轉換器的草稿儲存會逐一把所選來源寫入持久佇列。直接輸出成功或持久加入佇列成功後，才會清除已完成的輸入。沒有來源的設定不能儲存成轉換工作。手動驗證器儲存需要使用者明確解鎖保管庫；登記儲存需要相符的即時驗證碼，以及成功的加密保管庫寫入。寫入失敗會保留登記。新登記元件透過直接回呼確認實際儲存結果，不會使用帶有密鑰的 DOM 事件。

工具區段導覽會先檢查共用草稿登記冊，才替換表格。切換區段前，請完成或清除目前輸入。分頁關閉決定仍由主體外殼負責。瀏覽器重新整理後的復原只適用於已加入佇列的來源，不適用於尚未儲存的暫存輸入。瀏覽器導覽及跨來源終止的驗收仍屬主體責任。

驗證：`node --test tests/tools-intake.test.mjs` 會測試部分儲存後恢復而不重複、忙碌時阻止棄置，以及放棄操作保留已完成寫入和原始來源位元組。嚴格 TypeScript 檢查涵蓋提供者整合。實際建置的瀏覽器關閉對話框、相機許可及密鑰私隱驗收，仍需執行時驗證。

非同步完成時，會把目前指定的轉換器輸入及所選檔案參照，與操作快照比較。較新的修改仍屬未儲存，不會重設。工作程序要求、下載副檔名及操作歷史會使用該操作快照。登記確認同樣只清除未改動的表格輸入；寫入成功後會移除已完成的 QR 及項目，同時保留較新的帳戶或 URI 輸入。寫入失敗會保留待處理項目。

`tests/tools-draft-late-reset.test.mjs` 會以延遲的工作程序及保管庫確認，執行實際 TypeScript 方法。先前原始碼未能通過兩項延遲重設回歸測試；修正後通過，並另有檢查逐一涵蓋每個可編輯轉換器選項。這些方法測試案例不能代替瀏覽器驗收。
