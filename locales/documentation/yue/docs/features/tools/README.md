# 瀏覽器本機工具

`tools` 功能是網站及桌面呈現器共用的瀏覽器本機工作區，不需要原生配套程式或網絡要求。

## 轉換器

`pdf-lib` 1.17.1 提供檢查、分割、合併、擷取、重新排序、旋轉及標題中繼資料操作。產生的文件會在下載前重新開啟，並檢查頁面幾何、旋轉及中繼資料。複製操作保留所選順序，絕不寫入原始檔案位元組。輸入上限為總共 20 MiB、20 個檔案及 500 頁。取消或到達 30 秒期限時會終止專用模組工作程序。輸出只有在驗證後才會下載。

互動表格及加密 PDF 來源會被拒絕。PDF 簽章字典會被偵測並拒絕。其他不透明 PDF 功能不受支援。複製操作不保證保留註解、附件、大綱、文件中繼資料或無障礙結構。請勿把這些操作用於已簽署或封存文件。內容層面的頁面順序驗證及完整不透明功能處理仍待完成。

JSON 列陣列、CSV 及 TSV 支援引號欄位、內嵌分隔符及換行。Base64 及十六進位會編碼／解碼確切位元組。ZIP 建立使用隨附的 `fflate` 0.8.2，並重新剖析輸出。在實作有界解壓縮前，ZIP 擷取會停用。瀏覽器支援時，PNG/JPEG 輸入可透過獨立工作程序畫布編碼成 PNG、JPEG 或 WebP。解碼前的標頭檢查把尺寸限制為每邊 8192 像素及 16 百萬像素，並拒絕動畫 PNG。輸出會重新開啟並檢查尺寸。中繼資料會移除；JPEG/WebP 有損，而 JPEG 會以白色填補透明部分。Office 試算表轉接器及來源語言編譯仍不可用。

## 音訊及影片

有界媒體後端在一個專用傳統工作程序內，直接使用固定版本的單執行緒 `@ffmpeg/core` 0.12.10 UMD 核心。它不會啟動巢狀工作程序，亦不需要 SharedArrayBuffer。包裝套件的模組工作程序途徑不能把此 UMD 核心作為 ESM 預設匯入；傳統工作程序改用 `importScripts` 及核心原始碼公開的工作程序 API。所需本機資源副本、預期套件雜湊及 MIME 類型列於 [media-assets.json](media-assets.json)。根層建置／封裝整合必須複製全部四個檔案。URL 從 Vite 基底 URL 及目前文件解析，保留託管子路徑及桌面自訂來源。不使用 CDN URL 或上載。缺少資源或瀏覽器 API 不相容時會失敗，絕不改走網絡後備途徑。

**公開二進位分發仍待處理授權／原始碼界線。** 已安裝核心聲明 GPL-2.0-or-later，但 npm 套件只包含 `dist` 及套件中繼資料。[標籤 v12.15 的官方發佈](https://github.com/ffmpegwasm/ffmpeg.wasm/releases/tag/v12.15) 對應核心 0.12.10；標籤 v0.12.10 則對應較舊核心。v12.15 建置參照為 `71aa99d37c02a7b4c435275ca9ef50e612f6efa1`。其 Dockerfile 使用 Emscripten 3.1.40、FFmpeg n5.1.4、`--enable-gpl`、專案繫結及建置指令碼，以及各有授權的連結編解碼器／字型元件。LAME 原始碼使用浮動的 `master` 參照，因此套件本身不能證明確切建置原始碼修訂。分發 WASM 前，必須解決適用告示及完整對應原始碼／建置來源證明。[官方 FAQ](https://ffmpegwasm.netlify.app/docs/faq/) 確認核心授權跟隨 FFmpeg 及其連結元件；包裝程式的 MIT 授權不會取代那些授權。本文不宣稱已可分發。

### 可用性偵測

除非本機可用性偵測成功，否則媒體分類按鈕、目標選擇、直接執行及佇列輸入均維持停用。因此，目前部署若沒有已驗證的分發證明，會顯示待處理原因，同時保留可操作的文字工具。偵測首先從同一文件基底要求 `vendor/ffmpeg/distribution.json`。缺少或未獲核准的證明會在擷取 WASM 或探測編解碼器前停止。不會嘗試 CDN 或其他來源。擷取設有中止期限及回應大小上限。

日後由根層擁有的分發清單必須包含 `version: 1`、`coreVersion: "0.12.10"`、`licenseAndSourceVerified: true`、安全的本機 `.txt` `noticeFile`，以及剛好四筆 `files` 記錄。每筆記錄包含確切 `name`（`ffmpeg-core.js`、`ffmpeg-core.wasm`、`media-worker.js`、`media-plan.mjs`）、整數 `bytes` 及小寫 SHA-256 `sha256`。在對應原始碼及告示界線真正解決前，不得產生核准旗標。瀏覽器信任維護者撰寫的聲明，不會獨立判定法律合規。

讀取本機告示後，偵測會擷取每個有界資源並計算雜湊，再啟動暫用專用工作程序，執行核心的實際編碼器清單。每個目標分別檢查所需編碼器名稱：PCM、LAME、Vorbis、FLAC、H.264/AAC 及 VP8/Vorbis。缺少編碼器時，其相關目標會停用並顯示原因。雜湊不符、資源不可用、瀏覽器限制或編解碼器探測失敗，均會保持媒體停用。偵測結果只在目前頁面生命週期快取；替換已驗證分發內容後請重新載入。暫用工作程序會在偵測完成或逾時後終止。這些檢查證明本機可用性，不代表已完成轉換或已通過封裝執行時驗收。

音訊輸出為 WAV PCM、MP3、OGG Vorbis 及 FLAC。影片輸出為 H.264/AAC MP4 及 VP8/Vorbis WebM。簽名接受的來源為 WAV、MP3、OGG、FLAC、MP4 及 WebM，仍須通過實際 FFprobe 解碼。音訊擷取使用第一條音訊串流並捨棄影片。影片轉碼使用第一條影片及選用的第一條音訊串流。引導式起點／時長控制提供解碼後裁剪。不接受任意引數、檔名、路徑、編解碼器或重新封裝操作。虛擬檔案系統名稱從允許清單內偵測到的容器產生。通訊協定存取限制於工作程序的虛擬檔案。

每個來源最多 20 MiB。音訊時長最多 600 秒。影片最多 60 秒、1920 乘 1080 及 60 fps；影片輸出最多 1280 乘 720、24 fps。最多接受四條輸入串流及八個來源音訊聲道。輸出音訊統一為立體聲 44.1 kHz。MP3/OGG/影片輸出有損；中繼資料、章節及額外串流會移除。FLAC/WAV 保留標準化後音訊，不保留原本取樣率／聲道中繼資料。探測期限五秒、編碼期限 30 秒，外層工作程序生命週期為 30 秒。取消、暫停及中斷連接均會終止唯一工作程序。瀏覽器不提供每個工作程序的硬性記憶體配額；限制涵蓋接受的位元組、幾何、時長及執行，資源耗盡仍會失敗。本文不作更強的記憶體隔離聲明。

FFmpeg 輸出時間戳事件會報告實際已處理秒數，不會標作 CPU 完成百分比。直接轉換及持久佇列都會選用此後端。佇列仍每項工作只讀取一個來源，檔案總數沒有上限。交付前會以 FFprobe 重新開啟，驗證輸出大小、容器簽名、串流結構、時長及影片尺寸。達到輸出大小上限或時長遭截短的檔案會被拒絕。原檔案保持不變。實際 WASM 執行、編解碼器可用性及封裝後離線運作，仍待瀏覽器驗收；純規劃器檢查不是執行時證據。

## 程式碼及文字

引導操作可格式化或壓縮 JSON、統一 LF/CRLF 換行、編碼成帶 BOM 的 UTF-8 或 UTF-16LE、把帶 BOM 的 UTF-16LE 解碼成 UTF-8，以及把 HTML 字元跳脫為純文字。它們絕不執行來源程式碼。輸入／輸出上限為 2 MiB，無效編碼及帶 NUL 的二進位內容會被拒絕；JSON 巢狀上限為 64 層，逗號／項目數為 100,000。交付前會再次解碼或剖析輸出。JSON 格式化遵從 JavaScript JSON.parse 語義，包括數值標準化及重複鍵採最後值的行為。這些轉換均有披露；來源位元組不變。一般編譯器及 AST 改寫仍不可用。

八個分類各有獨立字面搜尋，以及相鄰正規表示式建構器，可編輯表示式、旗標、字元類別、群組、前後查看、量詞、Unicode 屬性、反向參照及測試範例。比對在一次性工作程序執行，期限為 150 ms。不支援的轉接器仍會顯示及說明缺少的能力。完整視覺化正規表示式圖及圖片預覽尚未完成。控制標籤及能力說明使用英文／廣東話翻譯回呼；確切轉接器及格式識別碼保持原文。不宣稱已通過離線封裝執行時或瀏覽器互動驗收。

## 持久佇列

佇列的檔案總數沒有固定上限。每個來源上限為 20 MiB，並分開存於 IndexedDB。輸入每次讀取一個所選檔案，先估計儲存容量；配額資料不可用或儲存失敗時會如實停止。每次只有一個工作程序處理一項工作；記憶體只載入一個有界來源。Web Lock 防止不同分頁同時處理。沒有 Web Locks 的瀏覽器不能處理持久佇列。中繼資料讀取及呈現分頁進行，每次 20 行，單次頁面要求最多 50 行。工作記錄不包含來源內容或路徑。

暫停會持久儲存並終止目前處理，保留原始來源以供重啟。重新載入而中斷的執行中工作會恢復至排隊狀態，最多自動嘗試三次。取消會移除已儲存來源位元組，遲到輸出不能令已取消記錄重新出現。完成輸出會留在本機，直到下載或移除。移除會刪除中繼資料及已儲存位元組。瀏覽器仍可能清除資料，所以這不是備份。進度報告已完成階段，不會虛構 CPU 完成百分比。直接轉換保留有界暫存批次；持久輸入才是處理任意長工作量的途徑。佇列 PDF 合併目前每項工作處理一個來源；直接合併接受多個有界來源。多來源持久合併、佇列批量選取及可攜結果清單匯出仍未完成。

## 驗證器

RFC 6238 驗證碼使用瀏覽器 WebCrypto HMAC SHA-1、SHA-256 或 SHA-512，六至八位數，週期為 1 至 86,400 秒。預設為 SHA-1、六位數、30 秒。測試涵蓋全部已發表八位數測試向量及六位數尾碼。

項目存於以 AES-GCM 加密的瀏覽器本機儲存保管庫。密碼透過 PBKDF2 SHA-256、310,000 次迭代及每次儲存新產生的 16-byte 鹽值衍生加密金鑰。每次儲存使用新的 12-byte IV。解鎖時明文項目留在記憶體，鎖定或中斷連接時會清除。已儲存密鑰沒有顯示或匯出途徑。登記輸入只接受使用者新提供的資料，並在儲存成功後清除。

所有保管庫建立及修改均使用一個本機 Promise 佇列，以及來源範圍內獨佔的 Web Lock。每次修改在持鎖期間重新讀取及解密最新已儲存密文，再計算變更，讓並行新增／移除及其他合作分頁保留彼此記錄。最後的密文修訂比較會拒絕協定以外的寫入者，而非覆寫其較新資料。鎖定會透過每次寫入前的世代檢查，令作用中及排隊操作失效，包括初次建立。沒有 Web Locks 的瀏覽器不能建立或寫入保管庫；不會嘗試不安全後備途徑。

新登記會產生本機隨機密鑰，並以隨附 `qrcode` 1.5.4 呈現真正 QR。手動密鑰只在新登記期間顯示，並列出演算法、位數及週期。確認接受相鄰一個週期範圍內的目前 RFC 驗證碼，錯碼會在提交至加密保管庫前被拒絕。手動 `otpauth://totp` 匯入會驗證支援參數及重複欄位。相機匯入使用瀏覽器許可、受限為 640 乘 480 的影格，以及帶有隨附 `jsqr` 1.4.0 的工作程序，30 秒後停止。影格及登記資料不會持久儲存、記錄或匯出。中斷連接或明確停止時，相機軌道會停止。

這是本機便利保護，不是伺服器認證。同來源指令碼可存取已解鎖保管庫。瀏覽器儲存可能被清除。遺失保管庫後重設需要清除此來源的瀏覽器儲存，並會永久失去項目。沒有遠端備份。帳戶搜尋重用獨立字面／正規表示式建構器，只篩選可見記錄，不搜尋密鑰。分組、重新排序、批量操作、受保護修改歷史及原生憑證保管庫整合仍未完成。剪貼簿寫入需要瀏覽器許可。現有保管庫成功解密後，透過本機動態模組匯入呼叫選用共用儲存的 `setLocalAuthenticated(true)`；鎖定則呼叫 `false`。世代計數器防止延遲匯入在鎖定後恢復認證。沒有可派發的 DOM 認證事件。建立新空白保管庫不會建立此認證狀態。

## 驗證

執行 `node --test tests/tools*.test.mjs`，測試合成 RFC 向量、保管庫竄改及錯誤密碼拒絕、支援 PDF 操作、來源位元組保留、表格往返轉換、編碼往返轉換、格式錯誤來源及位元組上限。佇列測試使用 `fake-indexeddb` 6.2.4，涵蓋 75 個排隊檔案、分頁上限、當機復原、重試上限、持久暫停、取消／延遲輸出、跨分頁移除而無孤立輸出，以及儲存預檢。保管庫並行測試使用真實加密及獨立控制的交錯執行，驗證並行新增／移除保留、加密期間鎖定、排隊寫入失效、修訂衝突及建立取消。真正產生的 QR 矩陣由 `jsqr` 獨立解碼，參數亦會經 URI 剖析器往返。配對測試拒絕錯碼並限制時鐘偏差。這些原始碼層面檢查不能證明已安裝執行時、相機、螢幕閱讀器或響應式版面驗收。

## 暫存草稿

分頁關閉提供者、部分持久輸入復原及已認證登記確認，請參閱[本機工具的暫存草稿](drafts.md)。草稿登記冊絕不序列化未儲存輸入。
