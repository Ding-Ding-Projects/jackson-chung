# 本機助手

靜態網站同桌面版使用相同嘅呈現程式。可選嘅桌面程序負責原生對話框、由作業系統加密嘅本機記錄、獨立 Git 歷史，同埋回環連線 Ollama 配接器。瀏覽器功能保留喺網站內。助手模組透過共用功能登記冊註冊 `companion`。

## 安全界線

視窗使用沙盒預載程式、內容隔離，而且呈現程序無法存取 Node。IPC 只接受 `desktop/security.cjs` 列出嘅操作，來源必須係封裝主框架嘅確切 app://jackson/index.html 來源。每個請求上限係 1 MiB。檔案匯入／匯出透過原生對話框選取；編輯器存取只接受由呢啲對話框建立嘅不透明控制代碼，唔接受任意路徑。外部導覽只接受 HTTPS 同郵件地址，而且唔可以內嵌登入憑證。瀏覽器權限提示會被拒絕。

可選嘅 Manifest V3 擴充功能只會喺 `https://ding-ding-projects.github.io/jackson-chung/` 以下運作。原生代理會獨立核對範圍、短期有效嘅請求時間戳記、唯一請求識別碼，同明確授予嘅配對功能。配對值只留喺瀏覽器工作階段儲存空間同桌面程序記憶體。撤銷桌面授權會令所有配對值失效，並取消執行中嘅模型工作。橋接介面唔接受 shell 指令或任意檔案系統操作。配對機制無法防範已經控制使用者帳戶嘅另一個程序，亦唔係針對呢種情況嘅身分驗證機制。

## 封裝與安裝

所有 `desktop/*.cjs` 必須連同 `dist/` 一齊發佈。`resources/tools/git/` 必須包含完整而可信嘅 Git 發行套件，包括 `cmd/git.exe` 同佢依賴嘅執行階段檔案。原始碼執行同封裝執行都唔會將 PATH 上嘅 Git 當成已內置工具。安全標準 app://jackson/ 協定只提供已解析嘅 dist 目錄樹，並喺 #tools 啟動共用呈現程式。佢支援本機 fetch 同工作程序，但唔授予 Node 存取權。缺少 Git 時會顯示復原狀態，加密儲存仍可繼續。desktop/native-host-launcher/ 專案提供自包含嘅 .NET 8 原生主機可執行啟動器。將佢發佈喺 JacksonChung.exe 旁邊，並將 desktop/native-host.cjs 同其 bridge/security 模組解封至 resources/app.asar.unpacked/desktop/。啟動器只執行該已安裝執行檔同固定指令碼，喺子程序環境設定 ELECTRON_RUN_AS_NODE，轉送二進位標準輸入／輸出，並捨棄診斷輸出。瀏覽器提供嘅引數一律唔會轉送。Squirrel 安裝／更新事件會呼叫啟動器登記流程，為 Chrome、Edge 同 Chromium 寫入每位使用者專用、名為 `org.jacksonchung.companion` 嘅原生訊息資訊清單。解除安裝只移除指向該次安裝嘅登錄項目。已提交嘅公開金鑰確立固定擴充功能身分 `nmehnkibdepbhmfggkofdpngpklinahg`；封裝時會重新推導並核實。資訊清單容許嘅擴充功能來源必須完全符合該身分。只有擴充功能原始檔，唔代表原生整合已安裝完成。

每次執行封裝指令碼都會使用全新而獨立擁有嘅暫存／輸出目錄。解壓之前，會以固定大小同 SHA-256 核對官方 MinGit-2.51.0-64-bit.zip 發行資產，再驗證封存路徑同內置 git.exe 版本、發佈自包含原生啟動器、斷言解封主機模組及預期 Squirrel 輸出存在，最後將輸出複製到 release/。如已有可信嘅 .NET SDK 8、9 或 10，會重用佢以 net8.0 為目標。否則，封裝流程會先核實官方發行中繼資料同固定 SHA-512，再下載官方固定版本可攜 SDK 8.0.414，解壓到工作快取並重新讀取核對。缺少或無效嘅官方位元組仍然係明確阻礙。只有當選定嘅 7-Zip 檔案缺失時，先會執行官方 electron-winstaller select-7z-arch 安裝指令碼。封裝包含公開擴充功能中繼資料；封裝指令碼從不讀取私人簽署材料。Squirrel 安裝／更新／解除安裝事件會透過相鄰嘅 Update.exe 建立或移除捷徑，並傳遞原生主機登記失敗。應用程式從不主動重新啟動電腦。除非封裝提供 `desktop/verified-update.json`，內含已核實來源、不可變更標籤、HTTPS 專案更新來源，以及兩個正常發行旗標均為 false，否則自動更新維持停用。實際發行中繼資料存在之前，唔會猜測更新端點或聲稱成功。

## 記錄與本機歷史

寫入記錄之前，作業系統加密必須可用。私人記錄檔會以不可分割方式取代。完整加密快照會記錄喺應用程式自有資料目錄下嘅獨立 Git 目錄，絕不放喺使用者原始碼資料夾。歷史唔會包含純文字快照。還原版本會建立新版本。歷史寫入失敗唔會捨棄已成功完成嘅加密儲存，結果會提示呼叫端修復套件。目前歷史介面列出最近 100 個版本，並支援只新增版本嘅還原方式。瀏覽同還原歷史需要本機密碼（首次解鎖時設定），解鎖工作階段為五分鐘，另有明確鎖定控制。日期／操作／正則表達式篩選、差異比較、標籤、保留期限、修剪同完整歷史匯出尚未實作，所以完整歷史驗收仍待完成。

## Ollama

請求只會前往 `http://127.0.0.1:11434/api/`，使用固定 tags/ps/chat/pull 路由，並拒絕重新導向。聊天同下載回應會以有界工作區塊串流傳送，支援取消，設有 15 分鐘逾時、8 MiB 輸出上限、最多八個並行工作，同完成工作保留一分鐘。批次下載以完整模型識別碼依序執行。介面從不猜測硬件或可用記憶體。缺少 Ollama 時會提供官方安裝連結。模型商店會枚舉官方 https://ollama.com/library 同每個模型 /tags HTML 來源連結嘅所有模型及完整變體，並跟隨 page/cursor/offset 分頁。佢會記錄每頁 URL、SHA-256、可取得嘅 ETag、整體不可變更回應身分、頁數、更新時間同上次成功更新。枚舉使用四個工作程序，限制為 2048 頁、總計 256 MiB 同每頁 4 MiB；觸及任何限制、解析器變更、頁面不可用或取消，都會令更新保持未完成，並保留之前已核實嘅快取。快取透過每次 100 行嘅 IPC 回應分頁存取。目前官方目錄冇列出嘅本機已安裝標籤，仍會保留喺共用清單。完整程度指已刊登來源回應嘅完整枚舉，唔代表對未刊登模型作出聲稱。已安裝同執行中模型使用官方 tags 同 ps 端點。喺 2026-10-10T06:56:11.413Z 進行嘅即時純來源擷取，取得 245 個模型系列、7439 個變體同 246 頁，整體回應身分為 89c27a119b62223d2dd1e61b3774987d511dd34248b9233aa407fe409794d8f4。呢個係網絡擷取證據，唔係已安裝執行階段或介面驗收。中繼資料回應上限為 1 MiB 同 4096 個模型，名稱有長度限制，數值中繼資料亦會核實為非負值。

## 驗證與尚待驗收項目

`tests/desktop-security.test.mjs` 會測試範圍、導覽、IPC 允許清單同資料大小限制。原始碼語法檢查同原生執行分開處理。已安裝 Squirrel 生命週期、原生主機登記、內置 Git 路徑解析、作業系統加密行為、原生對話框、實際 Ollama 服務串流、擴充功能配對／撤銷，同視窗大小／語言／主題／縮放擷取矩陣，都需要真實已安裝執行階段證據。原始碼測試唔能夠證明以上結果。

完整應用程式功能清單、歷史存取保護、完整擴充功能設定本地化／自訂，同 Status Hub 整合，仍然係整合負責人嘅驗收項目。擴充功能彈出視窗目前只提供最基本設定控制，尚未符合完整共用介面合約。

## 模型硬件證據與尚待商店驗收項目

所選標籤檢查會從允許清單內嘅官方登錄資訊清單取得確切層位元組，並使用有界、已驗證結構同回應雜湊。RAM 同架構透過作業系統 API 量度；只有 Electron 提供 GPU 身分時先會顯示。現有已核實配接器仍未能提供可用 VRAM、Ollama 後端／驅動程式支援，同執行中服務嘅實際儲存目的地。呢啲資料絕不會由模型名稱、配接器標稱記憶體或假定零值填補。可設定嘅上下文額外用量會明確標示為假設。適用程度會回傳 Runs well、Runs with limits、Unlikely 或 Unknown，附上時間戳記同完整證據；量度所得 RAM 不足可判斷為 Unlikely，缺少必要事實則維持 Unknown。建議唔保證一定執行成功。

目前商店支援純文字搜尋、有界 250 ms 工作程序正則搜尋、系列／安裝／適用程度篩選、標籤或已檢查大小排序、分頁導覽、有明確範圍嘅批次選取／反轉選取、可檢視嘅本機下載清單，同現有真正可取消嘅依序下載流程。每個實際助手搜尋欄而家都會開啟共用完整錨定正則表達式工作台。執行中／功能／量化／大小篩選、每個變體完整已刊登參數／上下文中繼資料、持久下載清單／項目狀態核對、可設定並行下載、準確總傳輸／儲存估算、完整離線疑難排解、快照／回復啟動設定，同已安裝畫面擷取驗收，仍未完成。來源枚舉或適用程度單元測試唔會令缺少嘅部分變成成功。

## 可編輯助手草稿

JSON 記錄修改同模型輸入草稿會加入共用分頁草稿登記冊。只有真實原生 `store.write` 回應確認 `saved: true`，JSON 先會變成冇未儲存改動。失敗、無效或缺失嘅確認都會保留已編輯文字。成功儲存期間同時發生嘅修改，仍會相對於已確認嘅確切快照保持未儲存狀態。載入或匯入唔可以暗中取代未儲存草稿。放棄只會將暫存 JSON 編輯器還原至上次已確認基準，唔會寫入或還原加密儲存內容。

模型識別碼、訊息同手動下載清單輸入都係暫存資料，冇持久儲存配接器。所以其提供者只提供放棄操作，唔會提供虛假儲存。放棄只清除呢啲輸入，唔會取消工作或改動已安裝模型。執行中動作、傳輸中請求、執行中工作同記錄儲存，會透過共用 API 阻止移除。元件拆除時會移除提供者登記。原生作業系統關閉行為同完整已呈現分頁關閉互動，需要另外進行整合／執行階段驗收。

助手嘅關閉動作會先處理共用草稿決定，再核對其他進行中工作，然後喺自身動作／請求計數器以外呼叫原生關閉。當可信關閉請求握手事件早於呼叫回應到達時，呢個安排可避免發起關閉嘅動作阻止自己。所有其他操作計數器仍會阻止移除。失敗或取消請求會保留可用工作區，傳輸失敗亦可重試。有順序嘅測試案例涵蓋提早事件情況，但唔能夠確立實際作業系統 IPC 次序或已安裝關閉驗收。

原生關閉握手會喺銷毀之前記低仍然有效嘅 webContents 參照。清理可重複呼叫而結果相同；視窗 closed 或內容 destroyed 時，會移除批准計時器、視窗監聽器、已記錄內容參照嘅監聽器，同 IPC 監聽器。銷毀之後唔會讀取 BrowserWindow.webContents。遲到 IPC 會透過已記錄參照同銷毀狀態檢查拒絕。回歸案例會令 getter 喺銷毀後拋出例外，並測試已批准關閉、外部關閉同內容先銷毀。呢啲原始碼檢查修復咗已觀察到嘅清理例外路徑，但唔能夠證明新封裝候選版本嘅已安裝關閉驗收。

## 助手搜尋與正則表達式工作台

三個實用欄位各自有獨立錨定共用工作台：官方目錄完整變體、會填入完整模型識別碼嘅已安裝模型選項，同本機版本標籤、日期及識別碼。每個欄位獨自管理預設純文字查詢、樣式、旗標、模式、驗證，同可獨立取消嘅工作程序。欄位識別碼包含所屬分頁身分，所以片段控制同已套用歷史都限制於該欄位。修改搜尋欄或工作台都會同步相同狀態；套用使用實際選定旗標。全域及黏附表達式會為每個候選項目重設 lastIndex。

搜尋篩選喺專用工作程序執行，設有 250 ms 時限、2048 字元查詢／樣式限制、100000 個值限制，同總文字 16 MiB 限制。工作程序失敗或逾時會顯示本機行內狀態，唔會顯示虛假匹配。欄位取代或元件拆除時，工作程序會終止。結果只包含索引，絕不包含匹配例子或擷取內容。JSON 快照或原生私人記錄內容都唔會複製到建立工具。版本篩選只涵蓋已載入嘅歷史標籤、日期同識別碼，唔包括加密快照內容。

共用工作台提供現有嘅構建工具、功能矩陣、解說、擷取／取代預覽、預期結果測試案例、明確片段匯入／匯出，同效能診斷。例子、案例同擷取內容維持該元件只作暫存嘅界線，唔會放入助手匯出、記錄歷史或日誌。當引擎冇提供 ECMAScript 引擎版本同逐步／回溯追蹤時，會明確標示不可用。原始碼測試證明獨立欄位、真實旗標語意、缺失欄位偵測、只含索引嘅輸出，同實際工作程序終止；已建置版面、鍵盤／觸控互動同已安裝驗收，喺呢個原始碼單元仍未核實。

所屬欄位修改會呼叫共用工作台 `setSearchState` API，唔會直接指派其 state 屬性。呢個做法會即時終止之前嘅評估、清除結果同有效狀態，並防止套用或儲存片段重用之前成功嘅樣式。每個欄位嘅轉送保護會忽略 setter 同步發出嘅變更事件；真正子元件修改仍會向父元件同步，唔會遞迴。如果子元件尚未呈現，同步會喺呈現後使用最新欄位狀態執行。整合案例會執行真實共用工作台方法，測試有效變無效同有效變新樣式；已安裝呈現按鈕驗收仍分開處理。
