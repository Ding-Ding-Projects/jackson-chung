# 設定說明及值來源

訪客設定每個可編輯值旁邊都有原有預設值，同可用鍵盤開啟嘅用途說明。展開後可以查看現時基礎值、整份記錄來源、最後已驗證儲存值同有效設定輸入。個別重設會還原實際內建值。空白聲線選項等值會明確顯示，唔會只叫做「預設」。

## 明確覆蓋範圍

手寫值清單包括語言、英文趣味、廣東話趣味、訊息表情符號、主題、密度、字款、字體大小、種子顏色、顯示名稱、減少動態、旁白、旁白語言、英文聲線、廣東話聲線、朗讀速度、朗讀音高、專注、低刺激、時間提示、逐件處理同保持步調。其他說明包括個人用字檔案、此工作階段螢幕閱讀器暫停、聲線試聽、停止語音、設定匯出、設定匯入、設定重設同版本還原。其他功能畫面仍有自己嘅文件，唔會默默聲稱已包括喺此清單。

## 唯讀來源資料

唯讀 `getSettingsProvenance()` API 會分開現時記憶體狀態同最後已驗證設定記錄快照。啟動記錄會區分缺少、已載入、無效同無法讀取。有效儲存記錄即使同內建預設值一樣，仍然會報告為已儲存。傳回快照會複製，唔會交出內部狀態。

成功寫入設定鍵會更新儲存快照，即使之後寫入歷史失敗亦一樣。設定寫入失敗會保留記憶體內現時編輯，同先前已驗證快照（如有），唔會自動回復。歷史寫入成功或失敗會獨立記錄。儲存功能可用，或者值同預設相等，都唔代表已持久儲存。

產生資料嘅位置會明確提供編輯、匯入、重設或歷史還原原因。任意操作描述唔會自行決定原因分類。呢個係整份記錄來源，未有追蹤每個欄位最後出處，說明亦會講清楚。同來源儲存事件如有格式錯誤，會保留現時值，但儲存來源會標示為無法提供。移除設定記錄會恢復內建預設值，並標示儲存記錄缺少。

## 有效輸入及限制

已有實際排程使用位置嘅欄位，說明會指出最後一條相符、已啟用而包括該欄位嘅規則。到期後會再次顯示現時基礎值。啟用顯示限制會將介面同旁白語言覆寫為英文。有效一欄描述設定輸入；裝置偏好、聲線供應同後續顯示行為仍可能調整實際結果。唔會聲稱每個欄位都有排程使用位置，亦唔會因為值相符而推斷欄位來源。

## 驗證

針對性測試會執行實際儲存、排程、說明資料同展開處理。手寫清單會偵測缺少說明同缺少實際顯示位置。測試包括本地化說明、準確預設值、個別重設、已儲存預設值、載入失敗、設定／歷史獨立寫入失敗、明確資料產生原因、儲存更新／移除，以及最後相符規則到期。原始碼測試同響應式樣式唔代表已驗證實際建置鍵盤操作、窄雙語版面或原生安裝結果。
