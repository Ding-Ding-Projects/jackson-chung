# 訪客偏好設定

瀏覽器會以帶版本的 `jc.settings.v1` 及 `jc.history.v1` 鍵，在本機儲存訪客選擇，公開個人檔案不會改動。設定包括三種語言模式、獨立英文及廣東話幽默值（1 至 5，預設 5）、外觀、旁白選擇、注意力偏好、導覽位置及釘選。變更會發出只包含設定的 `jc-state`。外殼接收此事件，並在自己的文字邊界使用匯出的翻譯輔助函式。

## 個人用語

設定中一直可見的檔案選取器接受 UTF-8 JSON，必須剛好包含 `schemaVersion`（1）及 `entries` 物件。每個項目鍵包含 1 至 160 個字元；每個替換值必須是最多 1000 個字元的字串。上限為 256 KiB、4096 個項目及八層巢狀。空白替換值會刻意移除文字。重複 JSON 鍵、重複原始字串、不安全物件鍵、未知欄位及版本，以及控制字元，均會在快取前被拒絕。驗證以不可分割方式完成。不隨附預設對應。獨立本機快取會在啟動時重新驗證，絕不匯出、寫入歷史、記錄或傳送。清除會還原隨附用語。替換只進行一次，避免替換值再觸發其他替換。不儲存來源檔名。

## 歷史及可攜性

設定變更最多產生 100 個瀏覽器本機快照。還原會附加新修訂。UTF-8 JSON 匯出包含目前設定及這些快照，但排除個人用語和檔案中繼資料。匯入會先驗證設定才套用。這是瀏覽器儲存歷史，不是以 Git 支援的歷史。儲存失敗時會說明變更只在目前分頁有效。

## 搜尋及外觀界線

目的地搜尋預設使用字面文字。明確正規表示式在可終止的一次性工作程序執行，設有 150 ms 逾時、輸入長度及清單上限。建構器支援字面包含、開頭、結尾及完整單字範本，並驗證旗標。完整進階正規表示式圖、豐富內嵌設定結果、精確元素跳轉及批量選取仍未實作。

外觀目的地提供真正的已登記目標編輯器。支援屬性、錨定及持久儲存，請參閱下方擴充編輯器章節。完整目標覆蓋及其餘能力清單仍需驗證。

## 旁白

旁白預設關閉。聲音選取器會列舉平台聲音，延遲列舉後更新，並保留穩定聲音識別。缺少聲音時會如實使用後備；依賴網絡的聲音會標示。預覽透過瀏覽器語音合成，依次播放英文再廣東話。瀏覽器無法偵測螢幕閱讀器，因此會提醒使用者使用閱讀器時暫停旁白。外殼可傳送帶有英文及廣東話文字、分類及選用錯誤旗標的 `jc-narrate` 事件。事件佇列會把一般文字去抖動 250 ms、使用三秒分類冷卻、替換同分類待播文字，並依序播放音軌。錯誤事實不會被冷卻抑制。由於可靠自動偵測螢幕閱讀器不可用，`setScreenReaderMode` 提供明確整合邊界。

## 本機定時規則

## 本機認證及導覽整合

未認證介面上的個人用語保持不作用，即使存在有效私人快取亦然。已驗證本機保管庫產生者，只有在實際本機認證成功後才可呼叫 `setLocalAuthenticated(true)`；登出、鎖定及重設必須清除此工作階段訊號。不接受任意 DOM 認證事件。訊號只存於記憶體，本身絕不是認證證據。缺少整合時會維持原始用語。載入器不隨附私人對應。

導覽支援左、右、上、下，預設為左。共用外殼必須讀取持久 `dock` 欄位，放置實際導覽。套用狀態時，廣東話的文件語言設為 `zh-HK`，英文／雙語設為 `en`，而 `data-locale` 保留完整模式。只接受整數的幽默值驗證防止文案索引超出範圍。色調調色盤衍生使用下述真實工具；完整建置對比驗證仍未完成。

## 擴充的已登記元素外觀編輯器

編輯器現在操作透過 `registerAppearanceTarget(element, stableId)` 登記或以 `data-appearance-id` 標記的真實元素。內容選單、Shift+F10/ContextMenu-key，以及靜止按住 650 ms，會在實際目標旁開啟有界面板。已登記的顏色、背景、半徑、內距、外距、字型大小、粗幼及字族變更，會經驗證並在本機持久儲存。編輯器控制本身亦有目標標記。最多儲存 200 個目標修補。不接受任意 CSS、URL、程式碼及事件繫結。外殼重新呈現後需要重新登記，才可重新套用已儲存修補；完整文件覆蓋、樣式歷史、匯出、版面編輯、文字／資源、結構、鎖及繫結仍未完成。

種子顏色現在使用 Material Color Utilities 0.4.0 的 `themeFromSourceColor` 衍生真實淺色／深色角色。系統外觀跟隨媒體查詢即時變更。兩種主題均以種子 `#006b60` 檢查中性色角色配對對比。這不能證明每個已呈現介面的對比或設計一致性。

## 瀏覽器本機呈現鎖

瀏覽器本機呈現鎖使用加鹽 PBKDF2-SHA256 憑證衍生（210000 次迭代），同步同來源分頁，支援重新命名，並強制英文，同時抑制私人用語及語言／幽默／上載控制。儲存損壞時會維持受限呈現，並報告記錄無法讀取。憑證絕不進入設定匯出或歷史。刪除此網站的本機記錄可重設鎖，因此這明確屬使用體驗鎖，不是安全邊界。跨已安裝應用程式的原生共用記錄橋接尚未實作，介面亦有說明。全面抑制未來功能、原生共用憑證及完整解鎖流程仍未完成。

私人用語啟用現在需要已驗證本機保管庫產生者直接呼叫 `setLocalAuthenticated`。不接受任意 DOM 認證事件。產生者必須在每次保管庫鎖定、登出及重設時清除此狀態。原始碼不隨附私人對應。

## 可重用分頁工作區

`src/state/tabs.ts` 只儲存帶版本的分頁中繼資料：獨立分頁 ID、目的地 ID、一般標題、群組 ID、釘選、顏色、建立／活動日期、順序、作用中 ID 及已關閉分頁中繼資料。精確欄位驗證拒絕任意表格資料、檔案位元組及非預期欄位。沒有小型分頁數上限；實際限制是可用瀏覽器儲存，寫入可回報錯誤。多個分頁可擁有同一目的地。元件支援方向正確的方向鍵、Alt+arrow 及明確移動控制、指標拖曳排序、一般關閉排除釘選、還原、群組、群組收合及顏色中繼資料。本機搜尋有相鄰工作程序正規表示式建構器；完整進階正規表示式能力仍待完成。

主體必須連接 `connectWorkspaceHost({create, mount, beforeClose, dispose})`。`create(tab)` 傳回獨立 DOM 節點；`mount(node, tab)` 在選取時附加同一節點。連接器在記憶體保留非作用中節點，設定 hidden/inert，接收 `jc-tab-close-request`，呼叫選用的未儲存工作否決，並棄置已關閉節點。它不會序列化私人值，亦不會在重新載入後還原表格狀態。外殼以真正目的地選取器處理 `jc-tab-new-request`。沒有連接器時，中繼資料元件不宣稱能保留非作用中檢視或提供可用關閉流程。

狀態 API 亦提供建立／啟用／關閉／還原／更新／移動／循環及群組操作。`jc-tabs` 帶有中繼資料。`cycleTab(direction, true)` 提供 MRU 循環。四邊分頁列方向使用現有停靠偏好；整個工作區的實際邊緣放置則由主體外殼負責。

尚待完成的分頁工作包括四個獨立範圍的探索搜尋、群組內正規表示式搜尋、群組名稱搜尋、應用程式範圍多工作區搜尋、完整群組排序／管理、批量關閉預覽、六種政策鎖、完整分頁外觀工具、完整設定介面採用，以及實際建置溢出／重排驗證。

## 指令覆蓋層

`src/features/search/palette.ts` 提供真正有界的裝飾覆蓋層、鍵入式本機搜尋及相鄰正規表示式工具、方向鍵／Enter／Escape、可操作已登記目的地、群組內容、釘選、卡片／全視窗選擇，以及經衝突檢查的自訂 Alt+Shift+A–Z/0–9 指令繫結。Ctrl+Shift+F 仍保留作開啟快捷鍵。主體呼叫 `registerPaletteDestinations(features, navigate)` 或 `registerPaletteCommands(commands)`，再呼叫一次 `installCommandPalette()`。`openCommandPalette(anchor)` 在來源元素旁開啟，關閉時把焦點還原至該處。應移除把同一快捷鍵送往不同目的地的競爭外殼處理器。

只顯示已登記指令。主體必須提供每個支援操作，才可宣稱覆蓋。豐富內嵌設定、精確元素跳轉、完整進階正規表示式圖／擷取／片段、批量結果行為、拖曳／調整大小持久儲存，以及完整窄版面／輔助技術驗證仍未完成。自訂繫結及釘選只儲存 ID，絕不儲存私人用語或頁面值。

## 獨立呈現鎖

`src/state/locks.ts` 實作六種確切政策：PIN、密碼、PIN 加密碼、密碼加 TOTP、PIN 加 TOTP，以及密碼加 PIN 加 TOTP。每個目標有自己的有序因素清單及憑證記錄；解鎖其中一個不會解鎖另一個。新 PIN 為 4–12 位數；密碼為 8–256 個字元。TOTP 使用使用者提供的 Base32 密鑰、RFC 6238 HMAC-SHA1、六位數、30 秒週期、一步時鐘容差及重播計數器拒絕。不會列印或匯出密鑰或 OTP。

預設瀏覽器轉接器把憑證記錄放在獨立的 `jc.local-lock-credentials` IndexedDB 資料庫。PIN／密碼驗證器使用獨立隨機鹽值，以及 PBKDF2-SHA256 的 210000 次迭代。驗證器資料會匯入成不可擷取 HMAC 金鑰。一般本機儲存只包含已驗證目標 ID、一般標籤、政策、時長及建立中繼資料。除非主體提供帶真正原生轉接器的 `setLockCredentialStore`，否則原生作業系統保管庫儲存仍不可用。瀏覽器本機儲存明確只是呈現鎖的對應實作，不是安全聲明。

每次失敗的手動／鍵盤提交都使用同一驗證器及重試預算。五次不符會觸發 60 秒本機冷卻。同一目標的並行解鎖嘗試會被拒絕。成功解鎖可准許此介面、有限分鐘數，或目前瀏覽器分頁工作階段。離開介面時，主體呼叫 `expireSurfaceLocks`。重新載入後全部鎖預設鎖定。重新鎖定須明確操作。替換／移除憑證需要現有鎖先解鎖；中繼資料寫入失敗會還原先前憑證記錄。

雙語錨定精靈提供全部六種政策、遮罩手動輸入、清除操作、帶 Backspace/Clear 的 PIN 數字鍵盤、時長選擇、披露確認、取消及焦點還原。其可搜尋清單保留鎖定項目並提供獨立管理。精靈會驗證每個必要因素；完整逐步多階段因素呈現、隨機鍵盤選項、批量管理、完整歷史，以及全部內容選單搜尋／採用仍未完成。

主體整合 API：

- `registerLockTarget(id, { label, allowLock, reason })` 登記合資格目標或不可改動的復原限制。
- `requireUnlocked(id)` 及 `withUnlocked(id, action)` 必須包住每個受保護操作、快捷鍵、指令面板啟用及修改。
- `registerLockElement(element, id, label)` 為可操作目標加入擷取攔截及可存取鎖定狀態；它會開啟錨定精靈，不會執行已鎖操作。
- `openLockWizard(id, anchor)` 開啟確切目標控制。除了已驗證中繼資料，`jc-lock-request` 及 `jc-lock-state` 是不帶資料負載的操作／狀態通知。
- `isLocked`、`relockTarget`、`getLocks`、`getLockPermission` 及 `subscribeLocks` 支援可見狀態。傳回中繼資料及許可記錄均為防禦性副本。

本單元以 `tab.<independent-id>` 檢查分頁啟用、關閉、排序及修改，並以元素 ID 加 `<id>:property:<css-name>` 檢查外觀修改／重設。外殼仍須在每個相關目的地、群組、控制、快捷鍵及未來功能採用包裝及操作檢查。一般擷取攔截不能證明停用原生控制包裝覆蓋、抗不可改動 DOM 變更，或全面採用。停用原生控制需要可操作主體包裝。目前精靈及清單不宣稱每個必要元素／狀態或鎖政策輸入途徑都有實際建置互動證據。

復原方法是清除此網站的本機儲存及本機鎖憑證資料庫。這些是使用體驗鎖，不是加密，亦不能防範另一個可存取瀏覽器的人。憑證儲存缺失時會保持封閉並提供可操作訊息；虛假認證結果不會授予存取。

## 導覽修正及精簡分頁列

每次儲存分頁狀態，現在都會檢查所選目標鎖。關閉作用中分頁會選取最近使用的已解鎖後備；沒有可用後備則不保留作用中分頁。還原已鎖的關閉分頁時，會先檢查許可才變更開啟／關閉清單。還原的瀏覽器中繼資料絕不啟用已鎖儲存目標。保留式主體監察鎖變更，隱藏／設為 inert 鎖定節點，不會掛載受保護內容。

指令面板結果導覽只限主要查詢欄位及結果列。巢狀正規表示式輸入、選單及自訂繫結編輯器保留自己的 Enter 及方向鍵行為。Escape 仍用於關閉覆蓋層。分頁方向鍵、Home 及 End 使用實際呈現順序，排除已篩走及收合群組的子項；全部成功鍵盤選取都會把焦點移至已呈現分頁按鈕。

分頁列預設精簡開啟：內部捲動列，加上可存取的新增、還原及管理控制。搜尋、相鄰正規表示式工具、每個分頁操作、群組及最近分頁控制，會在有界管理區域逐步顯示。垂直列限制高度；水平列自行處理水平捲動。實際 320 px 重排及新設計高度量度仍需建置證據。

外殼傳入 `.destinationTitles`，把 ID 對應至本地化字串。新目的地分頁記錄 `titleMode: destination`；修改標題則記錄 `titleMode: custom`。明確自訂標題按原文呈現。現有已知隨附標題使用目的地對應，未知舊標題維持不變。搜尋結果數量保留數字而非翻譯字串，並在呈現時重新翻譯，因此切換語言會更新快取結果，不用重新查詢。

針對性回歸測試在修正前觀察到鎖定後備、鎖定還原、巢狀指令面板 Enter、篩選後分頁方向鍵順序及 Home 焦點失敗。正面檢查亦涵蓋主要指令面板查詢、收合群組、自訂標籤保留及快取數量本地化。這些是原始碼／處理器檢查，不是瀏覽器像素或輔助技術驗收。

當篩選或群組收合隱藏作用中分頁時，精簡分頁列會保留一個循序鍵盤入口。可見作用中分頁取得 `tabindex=0`；否則由第一個可見分頁取得。`aria-selected` 繼續描述實際作用中分頁，此焦點後備不會啟用內容或解鎖任何項目。獨立篩選及收合測試案例均在修正前失敗、修正後通過。

## 採用完整共用正規表示式工作台

每個 `jc-local-search` 實例現在都在自己的插槽搜尋欄位旁，直接嵌入共用 `jc-regex-workbench`。預設為純文字。查詢、模式、旗標及模式類型透過共用同步輔助函式及欄位所屬變更／套用事件雙向同步。每個已掛載實例取得獨立欄位 ID 及狀態；不相符欄位事件會被忽略。無效表示式、工作程序錯誤或逾時，會保留先前結果並顯示明確訊息。所屬清單在自己的有界一次性工作程序評估實際項目；共用工作台只擁有明確輸入的暫存範例及擷取。

直接擁有的欄位包括訪客設定區段、設定歷史、實際元素屬性檢查、編輯器能力清單及已登記目的地搜尋。現有分頁、鎖清單及指令面板查詢，會透過可重用欄位繼承同一完整相鄰工作台。來源輸入保留無障礙名稱及清除操作。指令面板主要查詢標記仍在實際擁有者輸入上，因此巢狀工作台編輯器保留自己的鍵盤行為。

共用元件及工作程序從目前 main 原封不動匯入，提供真實引擎能力探測、建構片段、註解、擷取／比對及取代工具、暫存預期結果案例、計時／風險披露、片段及明確僅模式匯出。樣本及擷取絕不進入所屬欄位事件、設定歷史或匯出。片段持久儲存仍需在共用元件明確選用；父層不會偷偷儲存查詢或樣本。

針對性元件檢查涵蓋獨立欄位、字面跳脫、正規表示式模式／模式文字／旗標變更、不相符欄位事件、無效狀態拒絕及復原，以及手寫直接欄位清單。它們不能代替實際建置工作程序／CSP 運作、錨定版面、鍵盤、窄檢視區或每個介面完整性驗證。其餘較廣的指令面板／編輯器／導覽合約維持不變。

所屬清單的字面比對，現在透過有界項目工作程序，使用與共用工作台相同的跳脫模式及支援旗標。空旗標區分大小寫；隨附 `i` 仍不區分大小寫；黏附／全域表示式在每個獨立項目前重設 `lastIndex`。無效旗標會保留先前結果。回歸測試執行實際產生的工作程序程式碼及所屬搜尋函式，先觀察到大小寫不一致失敗，修正後通過。

## 項目搜尋工作程序生命週期

所屬清單工作程序現在會先宣告就緒，才接收其單次評估要求。啟動有獨立 2000 ms 期限；就緒後才開始原有 150 ms 評估期限，防止一般冷啟動消耗表示式預算。查詢、項目數及每項字元上限分別維持 1000、1000 及 10000。字面及正規表示式模式仍共用跳脫模式／旗標途徑，並逐項重設 `lastIndex`。

回應必須遵從確切 ready/result/error 協定。結果索引必須為整數、有序、唯一，且位於提交清單範圍內。建構、啟動、評估、解碼、訊息傳送、格式錯誤回應及取消途徑，全部會終止所屬工作程序、撤銷 Blob URL 並移除監聽器／計時器。`LocalSearch` 在開始另一個工作程序前，以及中斷連接或工作台狀態無效時，會中止先前實際工作程序。世代檢查仍防止延遲更新。搜尋失敗會保留先前結果，並報告工作程序／模式／期限限制，不會宣稱錯誤模式是唯一可能原因。

延遲啟動測試案例在修正前重現了先前錯誤的評估逾時。實際產生的工作程序原始碼亦在真實 Node 工作執行緒通過：220 ms 冷啟動成功、病態表示式觸及評估期限、取消會終止所屬工作程序。獨立邊界檢查涵蓋格式錯誤回應、建構／解碼／傳送失敗、啟動無回應、URL 釋放及過時／已中斷連接欄位更新。這證明上述可執行途徑的有界生命週期。已安裝瀏覽器啟動／CSP 行為及原本冷安裝事件，仍需目標執行時驗證；先前事件記錄沒有觀察啟動時間，不能單憑它證明確切原因。

## 分頁啟用語義

保留式分頁列使用原生 `button` 元素啟用。實際可聚焦元素擁有 `role="tab"`、`aria-selected`、完整無障礙標籤及游移 `tabindex`。這避開外框 Material 按鈕的 ARIA 委派界線，該界線不會把分頁角色或選取狀態轉交內部原生按鈕。原生控制使用共用表面、外框、選取、形狀及文字設計權杖，提供可見鍵盤焦點，最低高度為 44 px。水平及垂直列均保留相同啟用、鎖檢查、可見順序鍵盤導覽、焦點轉移及拖曳／排序處理器。

回歸測試執行實際 Lit 範本函式，驗證啟用目標是帶語義屬性及現有事件繫結的原生按鈕。它在先前自訂按鈕範本失敗，替換後通過。現有篩選／收合入口、端點焦點、可見順序及鎖回歸仍通過。這是範本邊界證據，不是已呈現瀏覽器無障礙樹斷言。實際建置無障礙樹、原生 Enter/Space、方向鍵／焦點、全部四個停靠位置及響應式視覺驗證，仍待整合擁有者的執行時驗收。
