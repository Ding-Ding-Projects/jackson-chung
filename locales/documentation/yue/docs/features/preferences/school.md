# 本機顯示限制管理

限制停用時，管理畫面會按訪客偏好顯示英文、廣東話或雙語。啟用後只用英文，說明亦唔會提及未能使用嘅顯示功能。自訂名稱會取代此控制嘅預設名稱。原有顯示選項會保留，停用後恢復。

## 更改及重設解鎖資料

首次啟用會建立六至二百五十六字元嘅本機解鎖資料。已有設定時再次啟用唔使新資料；停用則必須驗證現有資料。更改時需要現有解鎖資料同兩個相符嘅新欄位。操作會更新加鹽 PBKDF2 驗證記錄，保留現時啟用狀態同自訂名稱。之後舊資料唔可以再停用限制。

重設需要現有解鎖資料、兩把明確確認鎖匙同完成整條確認滑桿。操作會移除解鎖資料並停用限制，但保留自訂名稱。每次嘗試後及控制離開畫面時都會清空解鎖欄位。資料錯誤、新欄位唔相符、確認未完成或儲存失敗，都唔會報告成功。非同步驗證期間記錄如有改變，該次操作會失效。

## 本機界線及復原

記錄只適用於本機瀏覽器同一網站來源。同來源其他分頁會即時收到儲存變更。未有跨已安裝應用程式共用原生記錄功能：`nativeShared: false`。呢個係使用體驗限制，唔係安全界線。解鎖資料唔會加入設定匯出、歷史、記錄或文件。

本機記錄格式錯誤或無法讀取時，顯示限制會保持啟用，管理變更亦唔會接受。忘記嘅解鎖資料無法喺此還原。刻意清除此網站本機儲存會重設記錄，同時亦會移除此網站其他本機資料。冇託管復原服務，亦唔會聲稱有跨應用程式同步。

## 驗證

針對性測試會執行實際解鎖處理、持久儲存、錯誤現有資料、資料更換、重設確認、自訂名稱顯示、停用時全部語言、啟用時英文同原有顯示選項恢復。負面測試會偵測移除現有資料驗證嘅改動。原始碼檢查唔代表已驗證實際建置嘅鍵盤互動、響應式版面或原生安裝結果。
