# 專注模式

五個專注模式係獨立畫面選擇，全部預設關閉。可喺訪客設定自由組合，並非對使用者作評估，亦冇醫療效果聲稱。

## 專注

開啟專注後，在目前內容上方工作區列自行選擇已登記位置。其他導覽會降低視覺比重，離開該位置時內容色彩亦會降低強度。所有工作仍然可見及可用。「還原完整畫面」可一步關閉專注。「返回專注位置」沿用原有導覽及鎖定檢查。已移除位置會清楚顯示不可用，不能由此控制開啟。

## 低刺激

低刺激採用較平靜中性色盤，但唔會改寫已儲存種子顏色。框架非必要動態會減少，並尊重裝置減少動態偏好。非必要旁白會停止。冇操作按鈕嘅資訊、成功及進度通知會在顯示列靜音，警告、錯誤及可操作通知仍然顯示。通知中心保留全部工作階段記錄，包括靜音項目；開啟掣會同時顯示目前及已記錄數量，唔會刪除記錄或改變匯出內容。

## 時間提示

工作區列顯示今次頁面開啟後，以及上次觀察到有意義變更後經過幾多分鐘。輸入、變更及導覽會更新後者。指標及鍵盤活動會延後閒置提示，但唔會假裝工作內容有變。經過時間包括背景時間，畫面清楚講明並非工作量。時鐘只屬暫存，重新載入會重新開始，唔會加入歷史或匯出。

## 逐件處理

開啟後可在目前內容上方見到一項自行選擇嘅下一步。編輯、儲存及清除都有明確控制。單行文字最多五百字，只儲存在此瀏覽器。唔會由文件、表格、分頁或活動推測內容，亦唔會加入一般設定匯出或版本歷史。另有明確標示匯出控制，只有使用者要求時先將該下一步存成本機文字檔。請勿輸入秘密資料。清除會移除瀏覽器儲存項目。重設設定會關閉模式，獨立文字會保留至自行清除。

## 保持步調

自行開啟後，至少五分鐘未觀察到操作先會顯示溫和提示；頁面須可見，而且已登記草稿提供者冇報告進行中操作。每次閒置只提示一次。關閉後會等下次操作開始新一輪閒置；「暫時唔使」則精確延後十五分鐘。操作會延後下次提示，由背景返回亦會重新開始閒置時間。英文及廣東話趣味級別獨立調整提示語氣，唔會改變時間事實。學校模式保持全英文畫面。

## 儲存及驗證範圍

模式開關及安全專注位置識別碼使用一般有版本設定、修訂及明確設定匯出匯入。舊設定冇專注識別碼時會還原為未選位置，無效識別碼會被拒絕。下一步文字使用獨立有界本機儲存，唔會加入診斷、擷取測試資料、一般匯出或歷史。儲存被拒絕時保留目前已儲存內容，並報告限制。

可控時鐘測試涵蓋背景時間、已觀察變更、閒置輪次、精確延後、進行中操作、關閉及操作。儲存測試涵蓋空白、無效、過長及不可用輸入。通知測試確認記錄保留，警告、錯誤及可操作訊息仍然可見。刻意縮短延後時間後回歸測試轉紅，還原正確時間後通過。原始碼檢查唔能證明已建置畫面無障礙、排版、色彩強度、每個元件內部動態或已安裝時間行為；相關執行期驗證仍由整合負責人跟進。
