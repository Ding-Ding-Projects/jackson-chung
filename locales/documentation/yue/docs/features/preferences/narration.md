# 獨立旁白語言

旁白預設關閉。訪客設定可獨立揀英文、廣東話或者雙語，唔會跟介面語言轉。雙語先講英文，第一段完成後先講廣東話。試聽同事件隊列使用相同語言及聲線選擇；事件旁白關閉時亦可主動試聽。

## 本機設定

`narrationLanguage` 預設為 `en`。舊第一版設定同版本記錄未有此欄位時會移轉為英文。有效選擇係 `en`、`yue` 同 `both`；無效值會喺套用前拒絕。選擇包括喺本機儲存、歷史、匯入、匯出、重設及還原版本內。旁白控制器唔會儲存讀出嘅文字。

## 上學及安靜模式

上學模式暫時強制英文，唔會覆寫已儲存嘅旁白語言。關閉上學模式會還原原先選擇。低刺激會抑制一般事件旁白，保留必要錯誤事件。螢幕閱讀器暫停掣會喺此工作階段停止所有語音，包括試聽。瀏覽器無法可靠自動偵測螢幕閱讀器。

## 裝置聲線及時間

每種語言按穩定聲線識別保留自己嘅選擇。瀏覽器回報新聲線時會更新清單。已儲存聲線失效會改用第一個合適聲線；完全冇該語言聲線就跳過。控制項會顯示無聲線及需要網絡嘅聲線。速度及音高維持共用。一般事件保留 250 毫秒延遲合併及三秒分類冷卻；必要錯誤略過呢啲延遲。停止或更換語音會令舊完成回呼失效。

## 邊界及驗證

排程套用旁白仍待完成；此編輯器唔會聲稱已儲存排程能改變旁白。裝置聲線供應及建置後無障礙行為仍需執行驗證。聚焦來源執行檢查涵蓋語言獨立、試聽同事件順序、上學還原、安靜模式、取消、結構移轉及拒絕。呢啲檢查唔係安裝後執行證明。
