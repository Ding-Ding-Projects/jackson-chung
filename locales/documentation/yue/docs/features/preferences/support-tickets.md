# 本機支援通知單

支援通知單係虛構瀏覽器本機重設服務台。唔會傳送資料、建立外部通知單、發出網絡要求，冇服務收集描述，亦冇真人閱讀或回覆。清楚聲明喺每個趣味級別都保持不變。描述會喺本機儲存，因此會提醒用家唔好輸入密碼、PIN、驗證器密鑰、憑證或私人檔案內容。

## 流程

揀分類、虛構嚴重程度及 1 至 2000 字安全描述。建立時會分配本機通知單號碼，同由瀏覽器產生固定回覆。明確按鈕將狀態由已在本機建立推進至已由本機規則檢閱，再到重設指引已準備。嚴重程度唔會改變回覆，亦唔代表升級處理。冇自動真人回覆或回覆時間承諾。

清單提供本機搜尋及相鄰 regex 建立器、選取顯示項目、清除選取、所選狀態推進、所選 JSON 匯出及全部 JSON 匯出。分類同嚴重程度各自開啟貼住原控制嘅選項對話框，頂部有搜尋及完整建立器、無符合提示、選項箭嘴導覽、Escape 取消及焦點還原。描述有自己嘅清除操作，完成後焦點返到該欄位。停用嘅儲存、選取、匯出及最後狀態操作都有可見原因。主動匯出會包括輸入描述及準確本機記錄事實，唔會傳送資料。冇通知單匯入或程式內刪除操作。

## 儲存及重設

此網站來源嘅瀏覽器儲存會喺 `jc.support-tickets.v1` 保留最多 100 張通知單。驗證會拒絕無效分類、嚴重程度、狀態、重複識別、描述及時間。所有變更使用瀏覽器排他鎖，喺交易內讀取最新有效資料再寫入。瀏覽器未支援跨分頁鎖時會拒絕儲存並保留草稿。儲存失敗唔會覆寫記憶體記錄。跨分頁無效資料會保留現有記錄。清除此網站瀏覽器儲存時，通知單會連同本機設定及草稿一齊清除。

重設指引會指出目前網站來源同瀏覽器本機鎖憑證資料庫 `jc.local-lock-credentials`。用家先匯出要保留嘅內容，再自己喺瀏覽器設定查看及清除網站資料。此流程唔會開啟原生應用資料夾，亦唔會刪除資料。原生資料夾整合不可用，因此唔會顯示虛構路徑或假裝檔案管理器已開啟。

## 整合

功能匯出 `registerFeature(registry)`，喺說明群組登記目的地 `support`。外殼需要採用此登記。實際共用草稿提供者會將未儲存描述及選項改動接入儲存、放棄及取消處理。失敗保留輸入，寫入期間阻止移除，較新輸入唔會被較舊儲存完成清走。畫面鎖精靈嘅忘記密碼及重設說明按鈕，同畫面鎖清單重設按鈕，會發出 `jc-navigate` 並指定 `support`。根說明導覽及完整外殼路由驗證，喺採用前仍屬整合工作。

服務台同固定回覆框架使用獨立英文及廣東話趣味設定、三種語言模式，並喺共用限制啟用時使用嚴肅英文。所有標籤、分類顯示及搜尋字、穩定狀態碼同訊息都用相同有效語言，包括本機排程覆蓋及共用英文限制。記錄及匯出分類值保留原字。清楚錯誤及聲明保持事實，可信支援文字唔會經過個人用字取代。即使中性本機取代本來會匹配，聲明亦保持不變。控制使用 Material 元件、有名稱輸入、可見焦點、44px 目標、自動換行及窄畫面網格。建置後無障礙及版面仍待驗證。

## 驗證及限制

聚焦實際來源檢查涵蓋建立、狀態推進、儲存、準確所選匯出、記錄上限、無效輸入、原子儲存失敗、損壞儲存、跨分頁拒絕、聲明、語言模式、趣味級別、登記、畫面鎖入口回呼、瀏覽器重設邊界及會拋出錯誤嘅無網絡邊界。負面檢查會拒絕錯誤目的地、唔支援真人狀態、被改動匯出事實及注入網絡使用。呢啲檢查唔能夠證明建置後導覽、裝置版面或原生資料夾能力。批量刪除、持久匯出歷史、全面外觀及畫面鎖採用，以及外部支援服務，唔屬於此有限單元。
