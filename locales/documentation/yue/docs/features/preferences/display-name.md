# 訪客顯示名稱

本機顯示名稱偏好會更改工作區可見品牌、瀏覽器文件標題同原生標題列。呢個只影響訪客顯示，唔會改 Jackson Chung 嘅姓名、履歷或聯絡資料，唔會取代版權持有人，亦唔會更改套件識別碼、儲存鍵、更新來源或診斷身份。

## 空白名稱及文字處理

顯示解析器只會喺呈現時移除頭尾空白。空字串或全空白值會顯示固定原有名稱 Jackson Chung，儲存偏好仍然保持輸入原樣。似 HTML 嘅輸入會透過 Lit 當文字呈現，瀏覽器標題亦只會設定文字，唔會插入標記。

## 持久儲存及暫時規則

現有訪客設定記錄會喺本機儲存值，設定匯出同驗證匯入亦包括此值。重新載入會恢復儲存值。清除會保留空值並使用原有顯示名稱；重設會還原預設偏好。

定時規則可以透過有效設定暫時覆寫顯示名稱。外殼會使用該有效值，唔會取代已儲存基礎偏好。規則到期或停用後，會恢復當時嘅基礎顯示名稱。由於有效值已有實際使用位置，排程編輯器會列出顯示名稱為可用。

## 驗證及限制

針對性測試會執行實際解析器、外殼指派、瀏覽器標題同原生標題列範本、似 HTML 嘅純文字輸入、設定匯出／匯入／重新載入，以及暫時規則到期。負面測試會偵測缺少投影、指派、標題使用同排程登記。呢啲原始碼同處理測試唔代表已驗證實際建置版面、瀏覽器互動或原生安裝行為。
