# 瀏覽器本機定時設定

定時設定編輯器可建立及管理真正瀏覽器本機規則。外部 HTTPS 及 Home Assistant 來源未有實作。本文列明已驗證原始碼行為，以及仍待完成嘅套用及執行期範圍。

## 編輯流程

建立有名稱規則，選擇開始及結束時間、可選首次及最後開始日期、星期日子，以及覆寫數值。新草稿未選任何數值。「每日」會在同一條規則選齊七日。編輯保留規則識別碼，啟用、停用、複製及移動會操作真正有序清單，較後規則優先。規則、可用欄位及版本歷史旁邊都有獨立本機搜尋，連同完整相鄰正則編輯器。

儲存失敗後，無效或未填完草稿會保留。原生日期及時間輸入採用即時數值綁定，避免改寫瀏覽器未變數值。空白數字唔會當零處理。草稿未儲存時，轉換草稿須明確確認放棄。草稿提供者沿用既有保留分頁關閉流程。其他地方改過正在編輯規則時，儲存會安全停止，須先重新載入。

## 可用數值及待完成套用

目前框架會套用定時語言、主題、密度、字款、字體大小、種子顏色、減少動態及停靠邊緣。此編輯器只可新增選擇呢九項，規則數值只在本機，並按有類型設定格式驗證。

舊規則可保留其他已知欄位，包括趣味、訊息表情符號、顯示名稱、旁白及專注偏好；相關套用仍待完成。編輯器清楚標示不可用，載入、匯入及一般儲存時會保留，亦可取消現有勾選以明確移除。唔會提供似乎可操作但聲稱已套用嘅假控制。自訂元素外觀及自訂標誌定時設定亦未完成。每個畫面採用完整實際設定仍屬另一項工作。

## 時區及優先次序

所有時間使用編輯器列明嘅瀏覽器本機時區，包括開始但不包括結束，相同時間無效。跨夜時段屬於開始日嘅星期及日期，包括翌日凌晨部分。日期限制亦以該開始日計。

夏令時間按瀏覽器本機時鐘處理。明確預覽會拒絕跳過嘅本機時間，重複時間則用瀏覽器解讀。計算預覽會分清可套用欄位及待完成保留數值。預覽日期及時間都清除即用目前時間；只填一項屬無效。符合規則按清單次序逐項合併，較後規則只取代自己指定欄位。冇符合規則時使用即時基本設定，引擎唔會將定時覆寫永久寫入基本設定。

## 格式及持久儲存

規則匯出係包含 `version` 及 `rules` 嘅帶版本物件。每條規則有 `id`、`label`、`enabled`、`start`、`end`、`from`、`until`、`weekdays` 及 `patch`。未知規則欄位及未知修補鍵會被拒絕，識別碼係穩定有界字串，名稱不可空白且最多八十字。日期必須真實，星期須係星期日零至星期六六嘅非空不重複集合。每條規則至少覆寫一項已知設定，最多五十條規則。

舊版本一、只含規則嘅瀏覽器記錄會遷移，唔會自作數值。目前本機記錄另有有界版本快照。未知未來版本、損壞規則或損壞歷史在啟動時都安全停止，唔套用覆寫。其他分頁傳入無效更新時保留目前有效規則，並顯示本地化狀態。持久儲存完成後先更新記憶體規則及歷史；儲存失敗會保留原有狀態同未儲存草稿。

## 歷史、復原及攜帶

瀏覽器保留最新二十個規則版本，整份記錄上限一 MiB。版本包括最初規則及已儲存更改。復原會一次還原前一快照並記錄該動作，直至另一更改前唔會反覆切換。亦可還原指定舊版本。清除歷史須完成兩把確認鎖匙及整條滑桿，保留目前規則生效，並留下新最初快照。

JSON 匯出只含目前規則，唔含本機歷史。匯入最多二百五十六 KiB，拒絕重複 JSON 鍵，先驗證整份候選再改動。取代原有規則須兩把確認鎖匙及完整滑桿，移除規則及放棄未儲存草稿亦用同一確認方式。取消或 Escape 會保留目前狀態並返回焦點。待完成本機檔案讀取可取消，舊讀取唔會取代較新選擇。檢查匯入、移除或清除歷史期間，規則或歷史有變，會拒絕套用，唔會蓋過較新狀態。匯入亦唔會刪除獨立未儲存編輯草稿。

## 私隱及外部範圍

所有規則、版本快照、搜尋及預覽只在此瀏覽器。匯出可能有自行輸入名稱及已知舊設定，分享前請檢查。名稱或數值唔好輸入憑證或秘密資料。個人用字檔、私人對應、下一步文字、檔案位元組及任意表單內容唔屬於規則格式、匯出或歷史。

本單位冇外部來源網絡實作、Home Assistant 實體整合或作業系統憑證保管路線，唔聲稱已取得 API 回應、啟動來源或執行原生操作。本機功能冇 HTTP API，所以不適用 Postman 集合。

## 驗證

可執行測試使用真正引擎、驗證器、編輯器方法及已產生控制回呼，涵蓋跨夜及日期錨點、有序優先次序、每日語義、基本設定還原、重新載入、損壞儲存、原子儲存拒絕、複製、啟用狀態、復原、版本還原、無效匯入、過期檢查、未完成草稿、數字輸入、確認鎖匙、焦點返回及獨立趣味。手寫欄位清單分開九項已採用欄位及有效舊欄位。刻意破壞跨夜開始日錨點後回歸測試轉紅，還原後通過。

可控多倫多時區測試會拒絕春季跳時嘅預覽時間。原始碼及模板測試唔能證明瀏覽器選擇器、原生焦點、相鄰正則操作、響應排版、螢幕閱讀輸出、已安裝持久儲存或完整實際設定套用。英文、廣東話及雙語已建置畫面擷取與互動檢查仍由整合負責人跟進，完整定時設定合約仍未完成。
