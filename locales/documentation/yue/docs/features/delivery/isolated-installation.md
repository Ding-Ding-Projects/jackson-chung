# 獨立驗證安裝

`build-installer.bat /s --verification` 會產生真正 Squirrel.Windows 套件，使用獨立套件識別碼 `JacksonChungVerification`。實際每位使用者安裝目的地係 `%LOCALAPPDATA%\JacksonChungVerification`，冇使用環境變數重新導向。正式版本保留 `JacksonChung`，普通安裝程式輸出亦唔會改動。驗證安裝程式留喺私人建置輸出區。

內嵌、經嚴格驗證嘅驗證資訊清單，會喺作業系統實際應用程式資料目錄下選擇獨立應用程式同 Chromium 工作階段資料，名稱為 `JacksonChungVerification`。呢個模式會略過捷徑建立同瀏覽器原生主機登記，唔會開啟正式版本命名管道代理，亦會停用正式更新器。本機原生操作仍然使用真實封裝實作。呢個刻意限制嘅安裝可以確立封裝啟動同共用介面行為，但唔能夠證明正式瀏覽器登記、正式捷徑生命週期或更新器行為。

安裝之前，必須獨立解析同記錄實際安裝及設定檔目的地，要求兩者均不存在，並檢查正式版本目的地而唔改動佢。只可以透過有名稱嘅隱藏桌面，按確切安裝程式身分啟動。啟動之前，必須透過獨立檢查核實已安裝位元組同來源。收尾只可以停止已核實屬於工作嘅程序，並喺保留證據後，移除已聲明嘅驗證安裝／設定檔。絕不覆寫現有目的地，亦唔可以改動 `LOCALAPPDATA` 扮成隔離。

集中測試證明預設路徑保留、真正獨立使用者／工作階段目錄，同喺建立設定檔之前拒絕格式錯誤資訊清單。喺來源 `a25ee0b`，驗證安裝同 443 個封裝內容檔案一致，並喺隱藏桌面啟動真正已安裝介面。已實際測試原生功能狀態、取消未儲存關閉、加密合成記錄儲存、本機歷史確認，同載入往返操作。首次安裝結束碼不明；之後一次維護呼叫以零結束。正常關閉引發銷毀物件清理例外，所以冇通過，儘管確認原生錯誤對話框之後最終退出。修復後關閉路徑、解除安裝，同正式版本專用整合仍待完成。呢個模式唔係可棄置作業系統使用者或 VM，亦冇聲稱達到呢種更強隔離。
