# 套件內容完整性

Squirrel 套件必須包含應用程式所有暫存檔案，包括自包含原生啟動器、公開擴充功能設定、Chromium 聲明、呈現程式封存，同內置 Git 目錄樹。只有封裝程序成功，唔能夠確立呢份完整清單。

`scripts/package-payload.mjs` 會按相對路徑、位元組數同 SHA-256，為每個暫存一般檔案建立快照。安裝程式透過支援嘅 `additionalFiles` 選項，明確加入額外根目錄檔案。發佈至交付目錄之前，驗證器會讀取完整 NuGet ZIP 目錄，拒絕不安全或重複路徑同不支援格式、限制展開量、解壓每個項目，並驗證 CRC 同大小。之後要求每個暫存內容檔案都存在，而且位元組同 SHA-256 一致。

內容索引同驗證收據保留作私人建置證據，當中包含來源版本同封存摘要。內容缺失或被改動，會令根目錄安裝程式入口失敗；唔可以用空白但成功嘅安裝程式代替。

## 回歸與被拒絕候選版本

喺來源 `9a0219d40488748e87a1d58fe50ddfdfc952e65d` 嘅首次封存檢查，發現預設安裝程式範本漏咗 `JacksonChungNativeHost.exe`、`native-host-config.json` 同 `LICENSES.chromium.html`。該候選版本喺安裝之前已被拒絕，並保留作診斷。新驗證器已針對該真實候選版本執行，因缺少原生啟動器而拒絕。集中測試亦會拒絕有效 ZIP 中漏咗啟動器、CRC 損壞，同路徑穿越／私人建置路徑嘅情況，然後接受完整有效測試案例。

套件 CRC、內容／來源身分、未簽署狀態、簽署程序觀察、安裝、瀏覽器登記，同更新器行為，仍然係分開判斷嘅結果。程序追蹤不可用時會記錄為未核實，絕不當成冇簽署程序執行嘅證據。

修正後候選版本 `4548fb0c601da1c6ad67b73152a7eab810838de1` 通過確切安裝程式入口。全部 531 個封存項目通過 CRC 同大小驗證，全部 441 個暫存檔案同各自 SHA-256 一致。完整套件為 194,387,435 位元組，SHA-256 為 `eaffebb379908db79d607fad08130a46cdb629a7ac96ce8548ad6e751b28469a`；索引 SHA-1 為 `E451521B593B6DD633F28D54E91750768ADC4102`。Setup 讀取結果係 `NotSigned`。呢個套件早於之後嘅目錄、暫存草稿同原生關閉整合，所以唔係已安裝執行階段或現行來源發行證據。冇副檔名嘅執行階段 `version` 檔案，需要喺 NuGet 範本提供明確完整目的地檔名。

## 復原與安全

每次正式製作嘗試都有全新私人輸出目錄。無效套件會留喺原位，唔會複製到交付資料夾。唔好安裝被拒絕套件、覆寫無關安裝，或者刪除來源證據嚟隱藏失敗。真正 Squirrel 目的地必須喺可棄置使用者／VM，或文件記錄嘅受支援獨立目標內預先檢查。改動 `LOCALAPPDATA` 唔係隔離機制。
