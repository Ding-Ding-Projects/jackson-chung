# 交付與驗證

- [套件內容完整性](package-integrity.md)
- [已安裝驗證檢查點](installed-verification.md)

公開網站以靜態輸出部署喺 GitHub Pages。桌面助手係獨立 Windows 應用程式。瀏覽器相容功能應直接提供喺網站；原生存取係明確而可選嘅功能。

## 建置
執行 `build.bat /s` 建置靜態網站同共用呈現程式。執行 `build-installer.bat /s` 產生未簽署 Squirrel.Windows 套件。兩個入口都會傳遞子程序失敗。缺少支援嘅 Node.js 工具時，會從官方發行來源取得，並對照已刊登嘅 SHA-256 清單核實。呢個流程使用每位使用者嘅儲存空間，唔需要管理員權限。

## 證據界線
原始碼檢查、靜態輸出、部署、安裝程式封裝、已安裝操作、流動裝置互動、更新，同合約完整程度，都有獨立結果。任何成功建置都唔能夠證明其他項目。全新電腦自動準備流程，要喺可棄置嘅全新環境實際測試之後先算核實。

## 託管與公開記錄
權威公開首頁係 `https://ding-ding-projects.github.io/jackson-chung/`。聲稱發佈已核實之前，必須重新讀取實際線上部署、資產、來源中繼資料，同儲存庫 About 網站欄位。文件同 wiki 文章會直接封裝喺 `documentation.json`，供內部閱讀。

## 安全與限制
安裝程式未簽署，可能顯示未知發行者或 SmartScreen 警告。套用更新需要使用者明確操作，唔會重新啟動主機。登入憑證同私人使用者內容都唔會進入原始碼或公開證據。

## 驗證安裝

另外識別嘅 Squirrel 套件同確切限制，請參閱[獨立驗證安裝](isolated-installation.md)。

## Squirrel 生命週期結果

正式安裝同更新掛鉤會先建立捷徑，再登記瀏覽器原生主機。解除安裝會先移除捷徑，再取消相符原生主機嘅登記。兩個子程序都以隱藏視窗執行，逾時限制為 15 秒。即使捷徑子程序失敗，登記或取消登記仍然會執行；任何一個子程序回報錯誤、非零或缺失結束狀態，掛鉤都會以非零結束。驗證模式同過時版本掛鉤唔會啟動任何一個子程序。集中測試會執行實際擷取嘅掛鉤，涵蓋成功、失敗、逾時同無法啟動嘅子程序結果。呢啲來源測試唔代表已安裝捷徑、登錄或解除安裝驗收已通過。

## 正式更新

桌面更新器會喺啟動時檢查（首次啟動延遲 10 秒），之後每六小時檢查一次。會透過固定公開專案頻道尋找最新正常發行版本，解析標籤來源，再透過 HTTPS 核對中繼資料同套件內容。毋須內嵌未來版本收據。缺少已核實來源、驗證模式、未安裝應用程式、回退版本中繼資料同無效收據，都會顯示不可用。有更新時會先喺資源限制內核對索引同 SHA-1／SHA-256 套件雜湊。已核實內容會保留喺記憶體，透過工作專用迴環來源交畀 Squirrel，避免執行掛鉤之前重新下載到唔同上游內容。迴環伺服器只綁定 127.0.0.1，使用固定非秘密公開內容路由，核對 Host 同迴環連線來源，只接受完整相符 GET／HEAD 路由，限制同時請求數同存活時間，冇對外請求或應用程式請求日誌，結束時會銷毀緩衝內容同連線。準備就緒之前同重新啟動之前，都會核對 Squirrel 實際暫存套件雜湊同候選來源／版本。Squirrel 冇提供位元組進度事件，所以下載進度未能量化。全域持續顯示嘅準備就緒橫額同助手控制項會保留完整版本、發行說明連結同未簽署提示，並提供重新啟動應用程式以安裝同稍後按鈕。重新啟動會先處理所有現有草稿，再通過受信任本機關閉確認；取消或仍有操作執行時，工作區會繼續保留。已下載更新亦可能喺稍後啟動應用程式時套用。

實際正常發行版本包含 RELEASES、單一完整套件同 build-info.json 後，執行 `node scripts/verified-update.mjs <exact-tag>`，核對下載嘅發行內容同套件內嵌來源／版本中繼資料。只會寫入私人 `.agent/verified-update.json`。正式封裝會驗證並加入現有收據；驗證封裝會排除收據。缺少發行版本或來源證據時，唔會捏造收據。初版驗證器只接受單一完整套件來源，唔接受差異套件來源。離線、雜湊改動或版本不符，都會保持可見失敗狀態。唔接受憑證或任意更新來源網址。

集中來源測試涵蓋生命週期狀態次序、過時事件、無效／回退收據、損壞內容、驗證模式排除、草稿取消同受信任重新啟動批准。實際發行託管、下載／安裝、已安裝重新啟動、資料保留同回退驗收，仍需要可棄置 Windows 使用者或 VM。呢度唔聲稱已有正常發行版本或已安裝更新成功。

Squirrel 2.0.1 來源支援保留內容迴環路線。Squirrel 會將迴環傳輸地址寫入本機診斷日誌。呢個非秘密地址只提供已公開並核實嘅發行內容，冇認證或機密資源。應用程式唔會透過 IPC 提供該地址。診斷日誌保持私人，唔會加入來源、畫面擷取或發行版本。已安裝傳輸同生命週期驗收仍未核實。
